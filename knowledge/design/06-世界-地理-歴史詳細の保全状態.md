# 6. 世界、地理、歴史詳細の保全状態

旧資料にはТвердь星団、Неопалимая Купина、登録惑星名、巨大建造物、移動箱舟、亜空間本国、長期戦争、艦隊等の詳細がある。v2はこれを削除しないが、現時点では次の扱いに分ける。

| 詳細群 | 現在の状態 | 再採用条件 |
|---|---|---|
| 帝国最盛期、内戦、末期帝国、同盟への連続 | 正史 | Core v2に従う |
| 本国文明と遠征先の能力差 | 正史 | 数値は個別実装へ分離 |
| Твердь、Неопалимая Купина | 正史へ再採用 | [トヴェルジとクピナ](/world/15-トヴェルジとクピナ.md)を所有者とする |
| 登録惑星60件／120惑星／26語の一括カタログ | 固定正史として不採用 | 個別の惑星を使う時だけ一件ずつ再採用 |
| 移動箱舟 | 正史へ改稿採用 | [本国と移動箱舟](/world/19-本国と移動箱舟.md)を所有者とする |
| 19巨大建造物等の全固有名カタログ | 保護候補 | ゲーム上の役割が決まった一件だけ再採用 |
| 終わらない戦争の全詳細 | 保護候補 | 勢力、年代、責務拡張を確定 |
| 絶対年代、艦隊・人口・惑星数 | 未確定 | 複数資料の数値を統合後に採用 |

今回の再審査では、世界の入口になる地理と、本国の分散構造だけを採用した。旧資料の固有名を引用するだけで自動採用せず、必要な場面から候補を回収し、再採用手順を通す。

# 60. カエラヴィ標準身体の実装仕様

カエラヴィ標準身体は、Human互換の体、頭、顔、四肢と健康処理を維持し、背中の機能翼、尾羽、鳥類型の開放気嚢、系統Geneが表す固有器官を追加する。嘴、鳥脚、鉤爪は共通身体に含めない。

## 基礎能力

`CA_Caelavi`は次のrace基礎値を所有する。系統Geneと軍務xenogeneは、この基礎値へ通常のStat、Capacity、Gene効果として作用する。

| 項目 | 採用値 |
|---|---:|
| `baseBodySize` | 0.95 |
| `baseHealthScale` | 1.00 |
| `baseHungerRate` | 1.05 |
| `MoveSpeed` | 4.8 |
| `ImmunityGainSpeed` | 1.05 |
| `ComfyTemperatureMin` | 14℃ |
| `ComfyTemperatureMax` | 28℃ |

これらはRace基礎値であり、系統固有の暑熱、寒冷、食事、地形、飛行補正を先取りしない。

## 共通鳥類機能

### 機能翼

`CA_FunctionalWings`は、重力子フィールドを形成・制御することで、短距離の急速飛行、ホバリング、継続飛行を利用可能にする。フィールドは真空中でも機能し、自然生得型の飛行はEMPで不能化しない。飛行要求は、使用者、開始セル、着地セル、翼力、地形、屋内外、禁止区域、積載量を開始時に検証し、成立した飛行だけを発令する。

系統Geneは、離陸準備時間、飛行速度、維持消費、連続飛行時間、積載上限、着地点誤差へ倍率を供給する。飛行の正本は実行中のAbilityまたはJobが所有し、Geneは別の移動状態を毎Tick保存しない。

飛行能力の差異は、系統Geneが供給する速度、離陸準備、維持消費、連続飛行時間、積載上限、着地点誤差の倍率で表す。系統差を設けない性能項目は全系統で共通とし、飛行システムの未確定部分を先に専用Needへ分割しない。

Mapからの離脱は翼の能力でPawnを「飛び去る」専用処理にせず、Odysseyのシャトル発進・輸送処理へ接続する。シャトル離脱を表す専用Gene `CA_ShuttleFlightControl` は作成しない。

### 開放気嚢

`CA_OpenAirSacs`は、バニラと公式DLCが与える有毒ガス、毒性環境、真空曝露の進行量を1.25倍にする。独自の並行ダメージや第二の毒性Needを発生させない。

防毒、密閉、与圧、免疫等によって元の曝露が発生しない場合、開放気嚢だけを理由に曝露を新規生成しない。軍務ゼノジャームの`Breathless`相当効果は開放気嚢Geneを消去せず、元の曝露を無効化することでこの弱点を踏み倒す。

## 描画構成

標準Humanlike render treeへ次のGene render nodeを追加する。

| 層 | 内容 |
|---|---|
| 背面 | 系統別の左右一対の翼 |
| 胴体後方 | 系統別の尾羽 |
| 頭部 | 冠羽、側頭羽、裸面模様のうち該当するもの |
| 顔面 | 系統別の眼色と必要な顔面overlay |

翼と尾は胴体・頭部の通常apparelを置き換えない。Portraitと全方向描画は同じGene node定義を使う。遺伝性系統Geneを発現していない混成人は、`CA_FunctionalWings`の中立的な汎用翼と尾を使用する。

## 固有器官の表現

六系統の遠望網膜、衝圧鼻弁、裸面熱交換帯、湿地腱、翼関節固定腱、帰巣磁鉄小体等は、初期実装ではatomic lineage Geneの機能である。健康UIへ独立部位を追加せず、Gene欠落または上書き時に対応効果と外見を同時に停止する。

翼の負傷、切断、治療、義翼を採用するまでは、専用BodyDefとBodyPartを追加しない。その機能を採用する場合は、全系統共通の身体仕様として本書を更新し、欠損、Capacity、手術、保存、描画消去を同時に定める。

## 状態と失敗結果

- 無効な着地セル、禁止区域、積載超過、翼力不足では飛行を開始せず、Pawnを開始セルに維持する。
- 飛行中に着地セルが失効した場合、Abilityが保持する検証済み退避候補へ着地し、候補がなければ安全停止結果を返す。
- 系統textureが欠落した場合、別系統の外見へ置換せず該当nodeの欠落を報告する。
- `CA_OpenAirSacs`が独自曝露と公式曝露を二重付与した場合は実装不具合とする。

## 性能条件

- 飛行可能性、積載、系統倍率は飛行選択時と発令時に計算し、待機Pawnへ毎Tick再計算しない。
- 曝露倍率は対象Hediffまたは公式環境評価が更新される時だけ適用し、Map全体の大気を独自走査しない。
- 描画nodeはPawn自身のGeneと描画Cacheを参照し、他PawnまたはMapを参照しない。
- 系統人数や飛行中Pawnの全件一覧を毎Tick生成しない。

## 受入条件

1. 採用した七つのrace基礎値が生成直後と保存・ロード後に一致する。
2. 六系統と未分類混成の翼、尾、頭部、眼が全方向とPortraitで正しく表示される。
3. 開放気嚢は公式曝露だけを1.25倍にし、防護で元曝露が0なら新しい曝露を作らない。
4. 飛行失敗時にPawnを無効セルへ移動させず、理由を日本語で返す。
5. 身体処理と描画に全Pawn走査または常駐Harmony patchがない。

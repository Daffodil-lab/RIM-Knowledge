# 59. バニラ優先カエラヴィ種族実装境界

カエラヴィは、RimWorld 1.6と必須の公式DLCが提供する人型Pawn、健康、装備、仕事、Need、Gene、Xenotype、Pawn render treeを基盤に実装する。種族の安定IDは`CA_Caelavi`とし、`ThingDef ParentName="Human"`を継承する。Humanoid Alien Racesは必須package、Assembly参照、XML型、描画、保存形式のいずれも所有しない。

## 所有境界

| 対象 | 採用する所有者 |
|---|---|
| 人型Pawn、通常の健康、装備、仕事、社会関係、UI | `Human`から継承するVerse・RimWorld標準処理 |
| 種族識別 | Core所有の`CA_Caelavi` |
| 共通身体値と鳥類器官の機能 | [カエラヴィ標準身体の実装仕様](/design/60-カエラヴィ標準身体の実装仕様.md) |
| 遺伝性六系統 | Biotech標準`XenotypeDef`、`GeneDef`と[共通Xenotype契約](/design/61-遺伝性鳥類系統の共通Xenotype契約.md) |
| 軍務改造 | Biotech標準xenogerm工程と[軍務ゼノジャーム共通実装契約](/design/62-カエラヴィ軍務ゼノジャーム共通実装契約.md) |
| 翼、尾羽、冠羽、側頭羽、眼の表示 | Geneから追加する標準`PawnRenderNode` |
| 翼を使う移動 | Core所有Geneの能力とOdysseyを含む公開移動処理 |

カエラヴィは人間型の体と顔を使い、系統Geneが背中の翼、尾羽、冠羽または側頭羽、眼と顔面の差分を加える。標準状態へ嘴、鳥脚、鉤爪を追加しない。服、髪、帽子、Portrait、通常の人間用作業は標準人型処理を維持する。

## 身体と描画の段階

初期実装では、翼、気嚢、系統固有器官を独立した`BodyPartDef`にしない。器官の存在と機能をGeneが所有し、描画はGene render nodeが所有する。翼の切断、治療、義翼、翼手術を採用する段階でのみ、全系統共通の`CA_CaelaviBody`を追加する。

独自BodyDefへ移行する場合も、`ThingDef ParentName="Human"`、標準Pawn renderer、apparel、健康tracker、仕事、手術Recipe、Gene、Xenotypeを維持する。独自`BasePawn`、独自の完全な`PawnRenderTreeDef`、全人型Pawnへ作用する描画patchは採用しない。

## 生成と保存

カエラヴィを生成するPawnKind、Faction、Scenarioは、六つの遺伝性Xenotypeのいずれか、またはプレイヤーが構成した有効なカエラヴィXenotypeを明示的に指定する。開始時の六系統構成はScenarioが固定せず、プレイヤーの選択を許す。

生成後はrace Defとgene trackerが種族と遺伝性系統を保存する。ロード後もrace、endogene、xenogene、Gene描画、Need、年齢、装備、健康、社会関係を標準の各所有者から復元する。カエラヴィ判定は`CA_Caelavi`とのDef比較とし、Pawn名、Faction、外見、Gene一覧の全走査で推測しない。

## 失敗結果

- `CA_Caelavi`または必須の共通Geneを解決できない場合、通常Humanへ黙って縮退せずロードまたは生成を失敗として報告する。
- 指定Xenotypeが無効な場合、別系統を無作為に代入せず、生成要求へ不足Defを返す。
- Gene描画を解決できない場合、能力だけを有効にした完成状態とせず、欠落textureとnodeを検証エラーにする。
- 飛行先が無効、禁止、到達不能である場合、Pawnを直接移動させず通常位置を維持して理由を返す。

## 性能条件

- 種族判定はrace Defの定数時間比較とする。
- 翼、尾、冠羽、眼は標準render treeへ接続し、独自OnGUIまたはMap走査を追加しない。
- 系統効果はGene、Stat、Capacity、移動開始時の検査で処理し、全カエラヴィまたは全Pawnを毎Tick走査しない。
- 集団条件を持つ旅鳩系は、Spawn、Despawn、Map移動、Caravan構成変更で人数Cacheをdirtyにする。
- 描画、Gene、能力の測定は[RimWorldログ・性能診断契約](/design/53-RimWorldログ・性能診断契約.md)に従う。

## 受入条件

1. HARを無効にした標準必須環境でロードし、六つの遺伝性Xenotypeを生成できる。
2. 通常の服、髪、帽子、仕事、健康、社会関係、Portraitを維持する。
3. 各系統の翼、尾羽、頭部差分が全方向とPortraitで表示される。
4. 保存とロード後にrace、endogene、xenogene、描画、能力状態を維持する。
5. 全Pawn走査、全Gene走査、常駐Harmony patchを種族成立条件にしない。

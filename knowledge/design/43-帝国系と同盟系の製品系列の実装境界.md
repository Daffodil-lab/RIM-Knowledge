# 43. 帝国系と同盟系の製品系列の実装境界

帝国系と同盟系の製品系列は、同じ用途の品へ異なるゲーム上の役割を与えるための設計基準である。世界設定上の由来と意味は[帝国系と同盟系の製品系列](/world/42-帝国系と同盟系の製品系列.md)が所有し、本項はRimWorld上の表現だけを所有する。

## 基本対応

| 項目 | エンパイアモデル（仮称） | ユニオンモデル（仮称） |
|---|---|---|
| 性能 | 同用途では概して高い | 概して低いが、役割を果たす安定した基準性能を持つ |
| 価格 | 高い | 安い |
| 製造 | 高工数で、手作業・技能・調整の比重が大きい | 低工数かつ反復製造しやすく、大量生産に向く |
| 品質 | 品質差を表現できる品では品質システムを使用する | ゲーム上の品質を持たず、常に一定性能とする |
| 耐久 | 高性能化との交換で、同盟系より低い場合がある | 多くの場合、同用途の帝国系より高い |
| 運用上の役割 | 少数の高性能品、専門家向け、資源を集中した装備 | 標準配備、補給、交換、量産、長期運用 |

## 品質の扱い

ユニオンモデルには、RimWorldの品質段階を付与しない。同じDefの製品は、誰が何回製造しても品質による性能差を持たない。製造技能は、製造可否、作業速度、失敗、資源効率等へ使えるが、完成品を品質段階へ分ける根拠にはしない。

エンパイアモデルは、対象品が品質システムに適する場合、品質段階を持たせられる。高い技能と多くの手作業が高性能・高品質へ結びつく構造を基本とする。ただし、品質を持てない設備や消耗品まで、別の品質システムで無理に再現しない。

## 個別品への適用

この表は系列全体の傾向であり、全品へ同じ倍率を一括適用する仕様ではない。個別の`ThingDef`、Stat、価格、材料数、`workAmount`、耐久、Recipe、技能条件、品質Compは、各製品の実装所有者が用途とバランスに応じて決める。

個別品を系列へ登録する時は、少なくとも次を明記する。

- どちらの系列か、または例外・折衷か
- 同用途の比較対象
- 性能、価格、工数、品質、耐久のどこに系列差を出すか
- エンパイアモデルで必要となる手作業、技能、設備または校正
- ユニオンモデルで品質Compを持たないこと
- 一般傾向から外れる場合、その設定上・ゲーム上の理由

系列名は世界内の分類、DefNameや生成用Familyは実装IDである。同じ表示名を使う場合も両者を同一の所有者として扱わない。

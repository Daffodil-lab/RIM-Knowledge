# 49. HORIZON A1の実装境界

HORIZON A1は、Human Weapons計画で最初に実装する基準火器である。実在火器のDefを流用せず、独自の設定、表示、弾薬、Recipeを持つ。

## 識別

| 項目 | 実装値 |
|---|---|
| 表示名 | ホライゾンA1 |
| アーカイブ番号 | `139 04217` |
| 種類コード | `AR` |
| 型式名 | `HORIZON A1` |
| 推奨内部ID | `Shion_HW_HorizonA1` |
| 製品系列 | ユニオンモデル |

内部IDは実装時に衝突検査を行って確定する。表示名、アーカイブ番号、種類コード、型式名は設定クラスと一致させる。

## 必須Compと装備条件

- 品質Compを付けず、品質段階による性能差を持たせない。
- 人間Pawnが身体改造なしで装備、射撃、再装填できる。
- シオン専用Race、身体機能、感覚接続、エネルギー接続を要求しない。
- 人間専用にはせず、装備条件を満たすシオンその他の人型Pawnも使用できる。
- Cell、エネルギー結晶、弾薬結晶、常設電力を消費するCompを付けない。
- アーカイブ番号メタデータを持たせ、形式と重複を検証する。

## 物理仕様の共有

次の設定値はゲーム実装へ直接共有する。

| 設定値 | 実装 |
|---|---|
| 非装填時重量3.4kg | 武器の`Mass`を3.4kg相当とする |
| 標準装弾数30発 | `magazineSize`を30とする |
| 単射・全自動 | 対応する射撃モードを持たせる |
| 6.6×41mm HW | 固有の通常弾薬規格へ対応させる |
| 機械照準器 | 標準状態で照準可能とする |
| 追加光学照準器 | 将来のAttachmentまたは派生Defで追加できる |

全長810mm、銃身長420mm、ロングストローク・ピストン、回転ボルト、直線的な反動経路は、Bulk、取り回し、反動、発射間隔、命中、外観へ派生させる。

## 弾薬

Combat Extended環境では、`6.6×41mm HW`専用の`AmmoSetDef`と通常弾`AmmoDef`を新設する。実在する同口径または近似口径へ`similarTo`だけで置き換えず、弾速、ダメージ、貫通、反動、重量を比較検証する。

HORIZON A1は30発箱型弾倉から通常弾薬を装填する。弾薬結晶消費Adapter、エネルギー結晶、無限弾薬生成を併用しない。

バニラ環境で弾薬を抽象化する場合も、設定上は6.6×41mm HW弾を消費している。バニラ用AdapterとCE Ammoの効果を同時適用しない。

専用弾薬非互換は欠点である。他勢力の一般小銃弾を弾薬候補へ追加せず、補給が切れた時に旧式弾薬で射撃できるようにしない。

## 製造

武器本体のRecipe入力は構造材だけとする。Cell、エネルギー結晶、弾薬結晶を材料へ含めない。

次の二つの製造経路を許容する。

- 民間用の同盟製万能製造機による少量・多用途生産
- HORIZON A1へ対応する専用一体成型機による高速量産

材料数、`workAmount`、技能条件、研究前提、価格は、他勢力の一般アサルトライフルより優れながら、シオン正規小銃より安価で早く量産できる範囲に置く。二つの設備で完成品の性能差や品質差を作らない。

## 戦闘上の位置

HORIZON A1は、人間用の汎用制式小銃である。

- 一般的な他勢力製アサルトライフルより、実用射程、貫通、作動信頼性、耐久を高くする。
- シオン正規小銃、エンパイアモデル、高位特殊火器より低い性能帯へ置く。
- 単射を中距離の基準射撃、全自動を近距離と短時間の制圧へ使う。
- 狙撃銃、分隊支援火器、重火器の役割を奪わない。
- 人間向けの反動範囲を守り、高圧弾を理由に人間が扱えない反動へしない。

射程、命中、ダメージ、貫通、warmup、cooldown、連射間隔、反動、価格、耐久の最終値は、バニラとCombat Extendedの比較試験後に固定する。

## 発熱

高圧弾の欠点として、長い全自動射撃で発熱する。設定上の欠点をフレーバーだけへ置かず、バニラとCombat Extendedの双方で次へ具体化する。

- 持続射撃による命中または操作性の低下
- 警告温度
- 射撃継続限界
- 冷却中の射撃制限

発熱量、警告までの発射数、射撃停止までの発射数、冷却時間は、標準弾、通常環境、冷却支援なしという試験条件で決める。独自CompとCE側の機構を二重適用しない。

## 検証

- アーカイブ番号が`139 04217`で一意である。
- 種類コードが`AR`、分類番号が`139`で一致する。
- 品質Comp、結晶資源Comp、電力Compがない。
- 人間Pawnが装備・射撃・再装填できる。
- 30発弾倉、単射、全自動が機能する。
- CE環境では6.6×41mm HW以外の弾薬を装填できない。
- 万能製造機と専用一体成型機の双方で、同一性能の完成品を製造できる。
- 発熱処理がバニラとCEで二重適用されない。

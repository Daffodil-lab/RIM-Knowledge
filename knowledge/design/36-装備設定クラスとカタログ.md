# 36. 装備設定クラスとカタログ

装備の設定カタログは、個別品または系統が世界内で何として理解されるかを記録する。実装済みThingの一覧ではなく、設定クラスの所有者である。

装備・軍事カタログは、完成時の総件数を先に固定しない開放型カタログである。現在の候補数、採用数、実装数は、その監査時点のスナップショットにすぎない。既存項目の監査完了を、装備・兵器・防具・工具・軍事運用の追加終了とは扱わない。

## カタログが所有する項目

- 表示名、通称、系統名
- アーカイブ番号、種類コード、型式名、改修記号
- 拳銃、長銃、工具、軽装防具等の設定上の分類
- 民間、独立遠征、同盟旧制式、現代同盟標準、特化部隊、帝国・内戦期遺物、Red Star支援等の歴史層
- 発注者、発注目的・理由、当初の要求事項
- 設計した組織または個人、試作・量産・ライセンス生産を担った製造者
- 前身、競争試作、試験、事故、設計変更、採用、改修、派生型、製造移管等の開発経緯
- 当初目的を達成したか、達成できなかった点、得られた代替用途
- 公式試験、指揮側、使用者、整備担当、補給担当、民間利用者等の評価
- 試作、制式、限定配備、量産、退役、予備、払い下げ、復刻、遺物等の現在状況
- 想定された用途、使用者、持ち運び方、社会的な位置
- 定性的な取り回し、保守性、供給性、専門性、使用者適合
- 口径、弾薬規格、全長、銃身長、重量、装弾数、作動方式等の世界内物理仕様
- 遠距離武器が弾薬結晶から何を現地生成し、どこで保持・装填するかという方式
- 高度装備が外部エネルギー供給を必要とするか、外地でエネルギー結晶を使うかという事実
- バイポッド、銃架、交換銃身、冷却装置等の構造上の有無
- 過熱、低耐久、低信頼性、汚損等、利用者が認識する定性的な欠点
- 外形、色、装飾、仕上げ、音、触感の方向
- カタログ本文、フレーバーテキスト
- 関連する人物、組織、事件、生活場面

旧資料の「Diaspora系」は固定された組織分類として使わず、民間品、独立遠征向け、移住者の私物等へ具体化する。

古い装備を低性能、新しい装備を常に上位として書かない。旧品が選ばれる理由は、愛着だけでなく、修理性、供給、互換性、専門用途、意味技術、使用者との適合にも置ける。

## カタログ項目の最小形

個別品を採用する場合、少なくとも次を設定として決める。

| 項目 | 内容 |
|---|---|
| 表示名 | プレイヤーと世界内の利用者が呼ぶ名 |
| アーカイブ情報 | 三桁分類番号、五桁登録番号、種類コード、型式名、改修記号 |
| 設定クラス | 拳銃、携帯工具、儀礼防具等 |
| 歴史層 | どの時代・共同体・用途から来たか |
| 発注・設計・製造 | 誰が何のために求め、誰が設計し、誰が作ったか |
| 開発経緯 | 試作、試験、採用、改修、派生、製造移管 |
| 目的達成と評価 | 当初目的の成否と、立場・時点を分けた利用者評価 |
| 用途 | 誰が何のために持つか |
| 定性的な特徴 | 近距離向け、修理しやすい、儀礼向け等 |
| 物理仕様 | 該当する口径、寸法、重量、容量、作動方式、支持・冷却・交換装置 |
| 定性的な欠点 | 過熱、ジャム傾向、低耐久、整備難等 |
| 視覚方向 | 形、色、装飾、仕上げ |
| フレーバー | 世界内の意味を示す短文 |
| 現在状況 | 試作、制式、量産、退役、予備、払い下げ、復刻、遺物等 |
| 採否状態 | 正史、候補、歴史資料のいずれか |

正確な射程、ダメージ、素材、製造時間が未決でも、このカタログ項目は成立する。逆に、数値だけが存在しても設定カタログの採用済み品にはならない。

## 継続追加の規則

- 新規装備は、一件または一系統ごとに設定クラス所有者を追加できる。
- 現在の採用件数や実装件数を、将来の上限、完成条件、品揃えの割当数として使わない。
- 新規設定クラスは、表示名、分類、歴史層、発注・設計・製造、開発経緯、目的達成と評価、用途、該当する物理仕様、定性的特徴・欠点、視覚方向、フレーバー、現在状況、採否状態を記録する。未確定または非該当は空欄にせず区別する。
- 新規設定クラスの追加時に、Def、性能値、素材数、Recipe、製造時間、画像の同時完成を要求しない。
- 実装へ送る時は、その時点で採用済みの全カタログを一括実装せず、製品段階とゲーム上の役割に必要な品を選ぶ。
- 新しい装備が既存品と似ていても、由来、使用者、修理思想、供給経路、文化的位置のいずれかが異なるなら別設定クラスになり得る。
- 単なる性能差やTier差しかない場合は、新規設定クラスではなく実装上の派生、品質、Family候補として扱う。

## 軍事の語り

同盟軍を残虐趣味、冷血、秘密虐殺で特徴づけない。高い救命・回収能力、交戦規則、撤退、占領後の修復を実際に機能させる。

摩擦は、保護のための介入、敵味方の再分類、復活、避難、武装解除が、当事者の望む所属や時間と一致しない場合にも生じる。

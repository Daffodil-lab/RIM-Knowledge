# 24. 操作画面と情報予算

## 24.1 開示順

プレイヤーへの基本順序:

```text
魅力
  → 驚異
  → 信頼
  → 善意のすれ違い
  → 局所的選択
```

最初から帝国全史、魂の議論、惑星120件、全組織、全技術を説明しない。

## 24.2 媒体別

| 媒体 | 主に伝えるもの |
|---|---|
| 概要欄 | 独立人格の製造人類、遠征、豊かさと救援 |
| 種族説明 | 狐娘型の無性身体、人類としての自己認識、身体の自己所有、工業規格と一点物性、文明の連続性 |
| 建築・アイテム | 一用途、一歴史層、一生活上の意味 |
| 操作画面 | 現在値、理由、選択結果。設定講義を避ける |
| クエスト | 一件の成功と不一致、当事者証言、局所調整 |
| バックストーリー | 一人の生活・仕事・関係から世界を見せる |
| ザ・ハイヴ専用画面 | 単一中枢と端末の関係を誤解させない |
| レッドスター専用画面 | 利用可能な優れた支援、支援条件、現在の正式任務、報告・救援等の責務を示す |

ザ・ハイヴ専用画面はβ後期の情報予算であり、α版の出荷要件ではない。レッドスター専用画面は配布形態にかかわらず、通常開始へ混入させない。

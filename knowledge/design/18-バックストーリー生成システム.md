# 18. 旧バックストーリー生成システム

この生成案と現在のバックストーリー群は実用水準に満たないため、現行の制作規則や実装仕様には使用しない。Formation Record／Mastery Record、メタデータ、三軸タグ、Era、ThemeModule、希少度、AI生成、監査、実装規則は、比較、失敗分析、将来の再設計に用いる参考資料として保持する。

## 18.1 v2の情報源規則

バックストーリー生成時は次を用いる。

1. Core v2の確定事実
2. 対象モジュールで採用済みの追加正史
3. 制作ガイドの開示順と情報予算
4. 実装Defの制約
5. 旧カタログから再採用済みの候補

旧46MOD、120惑星、巨大建造物をタグに含むだけでは正史採用にならない。

## 18.2 表示本文

短いバックストーリーへ世界設定を詰め込みすぎない。

- 一件の具体的な生活、仕事、救援、失敗、趣味、関係を中心にする。
- 帝国／同盟差は標語より行動、住環境、食事、呼称、身体選択で示す。
- 善意のすれ違いを描く場合、成功と当事者証言を両方残す。
- 内部タグ、決定番号、制作語「善意の非対称性」を表示本文へ出さない。

## 18.3 自動監査

- 人格をAIや集合意識と誤記していないか。
- 通常シオンを、狐娘型以外の並行した標準種族として描いていないか。
- 狐娘型を、人格価値、法的地位、技術的上位性の根拠にしていないか。
- 狐娘型を生物学的な女性、人間型の内臓、生理現象と結び付けていないか。
- 可愛い人物だけを通常とし、凛々しい人物を例外化していないか。
- 帝国を全時代一様な悪にしていないか。
- 同盟人を冷血・無関心にしていないか。
- ソフェルが無設備で何でも解決していないか。
- Hiveを通常シオンの未来としていないか。
- Red Star支援を全開拓団へ配っていないか。
- 外部作品名、実在指導者、実在作戦を正史化していないか。

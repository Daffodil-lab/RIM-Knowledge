# 16. 主要人物・組織

旧資料にある水仙、ソフェル諸組織、ミチューリン農芸公社、サミズダート、Diaspora系企業、避難民回収案内の語り手等は、次の状態で保持する。

| 要素 | 状態 | v2での扱い |
|---|---|---|
| 水仙と革命 | 正史へ改稿採用 | [水仙](/world/14-水仙.md)を所有者とし、革命を一人の功績へ還元しない |
| ソフェル | 正史骨格 | 万能化せず専門家として扱う |
| The Hive中枢人格 | 正史骨格／実装目標 | Core任意モジュール |
| ミチューリン農芸公社 | 固有名を不採用、役割を改稿採用 | 実在人物名を外し、[農芸公社](/world/21-農芸公社.md)という共同体類型へ変更 |
| サミズダート | 旧称を不採用、役割を改稿採用 | [余白記録網](/world/20-余白記録網.md)へ独自化 |
| Diaspora系組織 | 独立分類として不採用 | 民間・遠征組織は[遠征共同体とRed Star](/world/08-遠征共同体とRed-Star.md)の独立勢力へ統合し、固有組織は一件ずつ作る |
| 避難民案内の語り手 | 保護候補 | プレイヤー向け開示順に合わせて改稿 |

個別人物の設定をCore v2へ上げる際、帝国全史の一律悪役化や、同盟の秘密ディストピア化を持ち込まない。

# 50. 装備庫接続と武器転送の実装境界

装備庫接続は、Coreが所有する専用装備庫と活動中Pawnの間で、実在する武器Thingを交換する仕組みとして実装する。Defから新品を生成する装備メニューや、Pawn inventoryへ全候補を不可視に保持する仕組みにはしない。

## 所有する実体

Core側に、転送可能な武器を保持する専用のEquipment Vault Bufferを置く。Buffer内の各武器は、通常の実物Thingとして一つだけ存在する。

武器は一時点で次のいずれか一か所にだけ存在する。

1. Equipment Vault Buffer
2. 転送中の予約状態
3. Pawnの手元、装備枠または明示された受取位置

同じ武器をBufferとPawnの双方へ残さない。交換取消、例外、保存、ロード後も二重所有と消失を起こさない。

## 交換取引

武器交換は、次を一つの取引として扱う。

1. 接続、権限、対象武器、受取可能状態を検証する。
2. 装備庫内の新しい武器を予約する。
3. 現在の武器の返却先を予約する。
4. 現在の武器を返却し、新しい武器を同じPawnへ渡す。
5. 両方の所在を確定して取引を完了する。

途中で成立しない場合、Pawnを不意に武装解除せず、交換前の武器を手元へ残して取引を失敗させる。転送中断を理由に武器を複製、削除、無償置換しない。

## 保持する状態

返却・取出しの前後で、少なくとも次を同じThing identityとして維持する。

- HP、損傷、品質
- 装填中の弾薬、弾倉、再装填状態
- 発熱、冷却、ジャム、摩耗
- Stuff、色、付属品、Attachment
- 固有名、アーカイブ番号、製造者
- 所有、Bond、Quest参照、未知Comp

装備庫へ戻ったことだけを理由に、修理、冷却、再装填、状態初期化を行わない。保管中の時間進行は、装備庫自身の仕様が所有する。

## 操作と遅延

同一Map、同一艦内、同一基地等の通常運用距離では、転送の物理的な伝播時間をゲーム内Tickへ細かく換算しない。UI上は一回の短い装備交換操作として扱い、長い運搬Jobを要求しない。

恒星間または別作戦圏の装備庫を、同じ即時リストへ無条件に統合しない。FTL供給、Mapを越えた無制限遠隔倉庫、通信だけで成立する物質複製にはしない。

## UI

接続中のPawnは、権限を持つEquipment Vault Bufferの利用可能武器から一つを選べる。

- 武器名、種類、弾薬、耐久、発熱、装填状態を表示する。
- アーカイブ番号と種類コードで検索・絞り込みできる。
- 取出し中、他者予約中、接続外、権限外を区別する。
- Pawnが現在持つ武器と、装備庫内の武器を同じ所在として表示しない。

装備庫の全内容を毎tick全Pawnから走査しない。入庫、出庫、装備変更、破壊、接続変更等のeventで利用可能索引を更新する。

## 接続喪失

接続、装備庫、転送端末、必要な稼働条件のいずれかを失った場合、新しい取出しと遠隔収納を停止する。Pawnが現在持っている武器は消去・強制返却せず、そのまま通常装備として扱う。

接続復旧後は、実在庫と予約状態を再検証してから交換を再開する。切断中に同じ武器を別Pawnへ貸し出したことにしない。

## 保管・接続基盤との境界

Equipment Vault BufferはCore側の専用実体であり、Core独自保管・接続システムの内部Storage、Network graph、Filter、UIを複製しない。

通常経路では、Core独自保管・接続システムの公開Import／Export契約から武器Thingを一度だけEquipment Vault Bufferへ搬入する。装備庫へ受領されていない保管基盤内部在庫を、転送可能武器として推測・表示・予約しない。

装備庫はCore独自保管・接続システムの公開Import／Export契約だけを使用し、搬入・返却・予約の成否を同契約から受け取る。

## Dormant Pawnとの境界

活動中PawnがDormant化する場合、手元の着脱武器は既存のDormant化取引に従って装備庫、Core独自保管・接続システムの通常入庫経路、またはMap上の安全な受入先へ返す。装備庫接続をPawn inventory内の無料保管へ変換しない。

## 検証

- 一つの武器Thingが一時点で一か所にだけ存在する。
- 交換失敗時に元の武器がPawnへ残る。
- HP、弾薬、発熱、付属品、アーカイブ番号が往復後も維持される。
- 接続喪失時に手元の武器が消えない。
- 複数Pawnが同じ武器を同時取得できない。
- 装備庫在庫を毎tick全走査しない。
- Core独自保管・接続システム内部在庫を直接照会・複製・予約しない。
- Coreの専用装備庫と通常装備が正規パッケージ構成で機能する。

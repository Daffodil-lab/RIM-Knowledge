# 71. カエルム文化輸出カタログ

カエルム文化輸出は、同盟自身の工業生産と競争する標準製品ではなく、作り手、家門、土地、軍務、移住の履歴を持つ民生文化品である。製品は芸術、文化、料理、衣服、装飾、手工芸品の六部門に属し、可能な限りRimWorld 1.6と公式DLCの品質、彫刻、本、楽器、衣服、家具、Ingestible、Drug、素材、Recipeをそのまま使う。

`Q`は標準`CompQuality`または同等のバニラ品質を持つ。`N`は品質を持たず、品質Gene、Inspired Creativity、品質補正を適用しない。

## 芸術 `Q`

| 製品 | フレーバー | バニラ接続 |
|---|---|---|
| 帝国飛翔戦役像 | 航空兵、翼、Gravshipによる遠征を記念する立像 | `Sculpture`、`CompArt`、`CompQuality`、Stuff |
| 機関都市浮彫 | 巨大機械の断面と居住区を金属板へ彫る壁面作品 | 彫刻Thing、`CompArt`、`CompQuality` |
| 渡りの星路像 | 星系を渡る鳥類系統と家族を抽象化した像 | `Sculpture`、`CompArt`、`CompQuality` |
| 家門肖像 | 複数世代、家門色、翼系統を一枚へ記す肖像 | `Sculpture`、`CompArt`、`CompQuality` |
| 重力艦・巨大機械展示模型 | 実在機の構造と生活区画を大型縮尺で再現する | `Sculpture`、`CompArt`、`CompQuality` |
| 喪翼記念碑 | 戦死者、失われた故郷、帰還不能者を記す碑 | 大型彫刻、`CompArt`、`CompQuality` |

芸術品のArt taleは作り手、題材、家門・連隊、製造地を標準記述へ接続する。10倍査定をThingのBeauty、MarketValue、資産価値へ埋め込まない。

## Catalog Defと真正性

各製品は`CaelumCulturalExportDef`へ次を持つ。

- 六部門の`categoryId`
- 完成`ThingDef`と公認`RecipeDef`
- `Q`または`N`の品質方式
- 許可するStuff、Ingredient、固定Recipeを示す製造規則
- 品質、耐久、Stuffを含むバニラ最終売却見積全体へ同盟後援倍率を適用できること
- 真正性を記録する製造・建築経路
- 買い手別に取引可能かを判定するtrade tag

公認品には完成時に`authenticityId`、製造Faction、製作者または工房、Recipe、製造tick、製造batch、作品・家門・連隊題材を一度だけ記録する。購入、鹵獲、再塗装、修理、minify、Map移動は真正性を新規作成しない。正規の製造記録を持たない同名Thingは通常品として扱い、同盟文化後援の対象にしない。

同盟後援では、真正な完成品について品質、耐久、Stuff、trade price improvement等を反映したバニラ最終売却見積全体を査定基準にする。高価なStuffを使った真正な文化品も完成品として十倍評価を受ける。原料Thingそのもの、未完成品、真正性記録のない同名品には後援倍率を適用しない。

## 性能と受入条件

- 品質は標準製造・建築完了時だけ決定し、全文化品を毎Tick検査しない。
- 真正性はCompまたは同等の保存Recordへ一度記録し、trade UIはThing参照から直接取得する。
- Catalog、Recipe、trade tagはDef読込時に索引し、商人画面を開くたび全Defを走査しない。
- 六部門から最低一品ずつ、QとN、異なるStuff、修理、minify、購入、鹵獲、保存・ロードを検証する。
- Q品だけが品質補正を受け、N料理へ架空のNormal品質が追加されないことを確認する。
- 代表Stuffと高級Stuffの双方で、真正な完成品のバニラ最終売却見積全体が後援査定へ渡り、原料Thingと未完成品には倍率が付かないことを確認する。

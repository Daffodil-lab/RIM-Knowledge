# 46. 装備アーカイブ番号体系

同盟の全装備は、アーカイブ番号と種類コードによって設計・型式単位で管理される。帝国から継承された装備、同盟成立後の装備、民間品、軍用品、Human Weapons計画品の全てを同じ台帳形式へ登録できる。

## 番号形式

アーカイブ番号は、空白で区切られた三桁と五桁の数字列から構成する。

```text
CCC NNNNN
```

- `CCC`は装備の分類番号である。
- `NNNNN`は、その分類内で設計・型式へ付与される五桁の登録番号である。
- 二つの数字列の間には一つの空白を置く。
- 先頭のゼロも番号の一部として保持する。
- 完全なアーカイブ番号は、必ず`CCC NNNNN`の八桁二群形式で表記する。

アーカイブ番号は、個々の実物へ刻む製造番号や所有番号ではない。同じ設計・型式として製造された実物は、同じアーカイブ番号を共有する。

## カタログ表記

標準的なカタログ表記は次の順序を使う。

```text
CCC NNNNN    TYPE    MODEL
```

- `CCC NNNNN`: アーカイブ番号
- `TYPE`: 種類コード
- `MODEL`: 型式名、通称、改修記号

型式名、愛称、製造者名、改修記号はアーカイブ番号へ含めない。改名や製造移管が起きても同じ設計である限り番号を維持できる。設計上の同一性を失う大改修には新しい番号を付与し、小改修は型式名側の改修記号で区別する。

一度正式登録したアーカイブ番号は別の装備へ再使用しない。退役、喪失、製造終了後も記録上の番号を保持する。

## 分類番号と種類コード

三桁の分類番号は、性能Tier、価格、品質、製造者、帝国系・同盟系の別を表さない。装備の主用途と種類だけを表す。

初期の火器分類は次のように登録する。番号とコードは提示例をそのまま転用せず、本体系用に新しく割り当てたものである。

| 113 | SMG | 短機関銃 |

| 139 | AR | アサルトライフル |
| 151 | BR | バトルライフル |
| 163 | DMR | 指定射手ライフル |
| 177 | SR | 狙撃銃 |
| 189 | SG | 散弾銃 |
| 203 | LMG | 軽機関銃 |
| 217 | GPMG | 汎用機関銃 |
| 231 | HMG | 重機関銃 |
| 247 | GL | 擲弾発射器 |

| 283 | AC | 機関砲 |
| 307 | TC | 車載・戦車砲 |

番号帯は、概ね次の用途へ予約する。

| 番号帯 | 大分類 |
|---:|---|
| 100–199 | 個人用火器 |
| 200–299 | 支援火器・重火器 |
| 300–399 | 車載・艦載兵装 |
| 400–499 | 防具・身体保護装備 |
| 500–599 | 工具・野外装備 |
| 600–699 | 電子・観測・通信装備 |
| 700–799 | 車輌・移動装備 |
| 800–899 | 設備・設置型装備 |
| 900–999 | 特殊分類・未整理遺物 |

同じ品が複数用途を持つ場合も、主要な設計目的に基づく一つの分類番号を持つ。検索用タグや副分類を追加しても、複数のアーカイブ番号を重複付与しない。

## 歴史層との関係

アーカイブ番号は、装備が帝国時代から存在したこと、同盟時代に新造されたこと、民間企業が製造したことを番号だけでは示さない。歴史層、製品系列、発注者、設計者、製造者、現在状況は別のカタログ項目として記録する。

アーカイブ体系成立以前の帝国装備と初期同盟装備も、保存・再製造・研究・配備の対象として登録された時点で番号を付与される。番号の大小を、設計年代や性能順位として解釈しない。

# 33. 代表工業資源

Coreで反復して扱う五つの代表工業資源は、次の実在する物資である。

| 資源 | 世界内での役割 |
|---|---|
| Cell | 物質、身体、設備の構成と変更を支える帝国由来の工業媒体 |
| エネルギー結晶（仮称） | エネルギーそのものを輸送・備蓄し、外地で身体や装備を稼働させる物理資源 |
| 構造材 | 建築、設備、基礎的な製造へ用いる規格化された物理材料 |
| 保守資材 | 設備、身体、装備の保守と修理へ投入する物理的な資材 |
| 弾薬結晶 | 全シオン系遠距離武器が、その場で固有弾薬を製造するために使う物理資源 |

五資源は、互いに交換可能な抽象ポイントではない。現地に存在し、運搬、保管、生産、消費できる物資である。Kombinatはそれらを独自の抽象残高へ変換せず、Matter Networkを利用する場合も元の品として扱う。

「代表」は、同盟文明がこの五種類しか資源を持たないという意味ではない。Coreの開始、基礎工業、検証で反復して扱う基準集合を示す。将来の製品や拡張が別の資源を追加することを妨げない。

同盟通貨、人口、労働、研究、団結、名声、防衛準備、装備ポイントはこの五資源に含めない。同盟通貨は金融残高、その他は状態、能力、評価または計画値であり、物理在庫ではない。

エネルギーは、この五資源と同列の一種類の物質ではなく、発生、供給、蓄積、輸送、消費を扱う上位ジャンルである。凝縮真空はエネルギー分野の技術または形態として存続するが、五資源の輸送用Thingはエネルギー結晶が担う。

個々の物理形態、等級、包装、危険性、製造主体、製造工程、世界内単位は各資源の所有者が扱う。DefName、スタック数、重量、価格、Recipe、工数、製造時間等は実装所有者が扱う。

# 0. 結論

Coreの最初のプレイ可能対象を、**本国政府の正規指揮系統と保証された補給へ恒常的に属さず、自分たちの判断と共同資産で辺境に暮らしを作る小規模な独立開拓団**へ固定する。ただし、小規模なのはα版で選ぶ一例の規模であって、「独立開拓団」という正史分類の上限ではない。

「独立」は同盟への反乱、追放、犯罪、通信断絶を意味しない。独立開拓団は同盟の人格権、身体の自己所有、技術、文化、善き世界を作る使命を受け継ぎながら、現地での目的、労働、生活、救援、他共同体との関係を自分たちで決める。

初回Coreは次の一本を完成させる。

```text
三人の独立開拓者が辺境へ到着する
  → 限定された技術の種と共同資産を確認する
  → shelter・電力・食・修理を成立させる
  → Kombinatの倉庫Networkを構築する
  → Storageへ保管し、生産・消費・流通を設定する
  → 三段の多段生産を完了する
  → 同一ビルドで保存・ロードして生活を続ける
```

Red Starは「保証された本国支援を持つ別の開始関係」として比較対象に残し、βで完成させる。The Hiveは設定を保全し、β後期まで実装しない。

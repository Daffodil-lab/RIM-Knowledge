# 3. 標準Core開拓団

## 3.1 標準開始の成立経緯

Core α版の標準団は、本人たちの合意で組織された民間の小規模開拓団である。

- 出発は自発的である。
- 携行身体、記録、道具、技術資料、共同設備は合法的に取得している。
- 特定の国家任務や戦争遂行を主目的にしない。
- 最初から帰還不能とは決められていない。
- 到着先に完成済みの本国施設はない。
- 本国からの定期支援契約はない。

出発理由は一つに固定しない。生成される三人の背景に応じ、次を併存できる。

- 新しい土地で暮らすこと自体を望んだ。
- 小さな工房、農園、診療所、研究所を自分たちで運営したい。
- 現地共同体の救援、交易、環境修復へ関心がある。
- 大規模組織より少人数の共同体を好む。
- 旅、景観、未知の料理、生態系、工芸を楽しみたい。
- 契約仕事の完了後、その土地に残ることを選んだ。

反帝国・反同盟思想を共通動機にしない。

## 3.2 三人の創設者

**Core α決定:** 標準開始人数は三人とする。

これはシオン社会の標準家族数や政治単位ではなく、RimWorldの初期操作、技能分担、関係描写、負荷を両立させるゲーム上の開始値である。

三人は固定階級ではなく、次の機能を共同で満たす。

| 機能 | 必要な理由 | 人物像の例 |
|---|---|---|
| 建設・修理・工業 | shelterと技術の種を現地設備へ育てる | 精密工、設備保守者、仮設建築士 |
| 生活・医療・生態 | 機械身体、他種族の栄養、環境、救援を維持する | 臨床医、動物診療助手、園芸者、救護員 |
| 調査・交渉・記録 | 土地、資源、近隣共同体、約束を扱う | 資源調査員、記録係、交易員、案内人 |

一人が複数機能を兼ねてよい。全員を専門家にせず、趣味、不得手、過去の仕事、関係を持たせる。

## 3.3 ソフェルを必須にしない

標準開始にソフェルを保証しない。

- 完成済み機器の利用と基本保守は一般技術者でも可能である。
- 未知状況へイェツィラーを記述・校正できるソフェルは稀少な専門家である。
- ソフェル不在でも初期工業と生活が成立する。
- ソフェル加入は後続の人物、クエスト、研究、開始バリアントにできる。

ソフェルを初期必須にすると、通常工学と標準技術が無力に見え、専門家万能化も起きるため避ける。

## 3.4 身体構成

三人は独立人格であり、身体は各自が所有する。

- 全員が狐娘型の標準遠征身体を使用する。
- 身体は中性・無性で、人間型の内臓や生理現象を持たない。
- 共通の工業規格、交換可能な接続部、診断方法を使う。
- 完成した構成は、本人の用途、感覚、美意識、外装、修理履歴へ合わせた一点物にする。
- 狐娘型という共有身体を、技能、性格、法的地位、身体品質の差へ連動させない。
- 初期実装では大幅な非人型身体を生成しない。
- The Hive端末を混入させない。

規格化は三人を同一品にするためではなく、辺境で修理し、部品を交換し、後から機能を足せるようにするためである。身体差は、見た目だけでなくモジュール、個別調整、衣服、装飾、修理履歴、用途選択、本人の好みを示す。

α版はXML／Defで成立する固定の標準身体表現を許可する。Platform、Interface、Module、Pawn別Configurationと交換UIはβで実装し、αの固定Defを最終的な身体正史や拡張上限にしない。

# 8. 標準開始シナリオ

## 8.1 表示名

**Core α決定:** 仮の表示名を次とする。

- 日本語: `独立開拓団`
- 英語: `Independent Expedition`
- DefName候補: `Shion_IndependentExpedition`

公開タイトルは翻訳とWorkshop全体名の確定時に調整できる。DefNameは実装後に不用意に変更しない。

## 8.2 開始文案

> あなたたちは命令でここへ来たのではない。帰還を禁じられたわけでも、救われるのを待っているわけでもない。三人で選び、三人で運べるだけの身体、記録、工具、工業媒体を持って、この土地へ降りた。  
>  
> 本国の豊かさは遠い。けれど、その作り方を何も知らないわけではない。まず屋根を作り、食卓を作り、壊れたものを直す。やがて、この場所にしかない善い暮らしを作る。

開始文で反乱、秘密、国家任務、救援艦隊を示唆しない。

## 8.3 開始人数と生成

- 三人のシオンPawnを生成する。
- 年齢、背景、身体形態、性格、技能は許容範囲内で変化する。
- 建設／工業、食／医療／生態、調査／社交の最低機能を団全体で満たす。
- 一人を固定主人公にしない。
- ソフェルを保証しない。
- The Hive関連PawnKind、Hediff、端末を生成しない。
- Red Star支援状態を付与しない。

## 8.4 初期装備の原則

初期装備は「民間の遠征準備」であり、裸同然でも軍事遠征でもない。

| 分類 | α方針 |
|---|---|
| 衣服・防具 | 環境対応の作業着。重軍装は与えない |
| 武器 | 野生動物と小規模脅威へ対応できる護身装備。正規軍火力は与えない |
| 医療 | 最初の負傷へ対応できる携帯医療品 |
| 食 | 数日を凌ぎ、現地生産へ移る量 |
| 工具 | shelter、発電、修理を開始できる携帯工具 |
| 工業媒体 | Kombinatの初期論理残高として与える |
| 文化品 | 一つの調理・音楽・記録・装飾系小物を候補にする |
| 車輌 | α版では必須にしない。車輌基盤確定後に再検討 |
| 動物 | α版では固定しない。後続開始バリアント候補 |

具体的なThingDefと数量はバランスDefで調整し、正史化しない。Profile上の指定方法は、次の二種類へ分ける。

### 8.4.1 具体装備指定

特定の品でなければ開始の人物像またはゲーム進行が成立しない場合に使う。

- 指定した`ThingDef`
- 必要なら素材、品質、数量
- 装着、所持、地上配置、共同倉庫の別
- 個人所有、共同所有、貸与の別

個人の愛用品、記念品、必須工具、固有装備を「武器」「文化品」等の抽象枠だけで指定しない。

### 8.4.2 装備ファミリー指定

「装飾ヘルメット」「標準射撃武器」「軽装防具一式」のように、作者が登録した同用途・同性能帯・同費用帯の候補集合を指定する。

- 安定したFamily ID
- 役割と装備部位
- 明示的な候補ThingDefまたは基礎ThingとStyle／装飾差分
- Family内で許容する性能帯・費用帯
- 非物理的な装備ポイント費
- 数量または数量範囲
- 装着、所持、地上配置、共同倉庫の別
- 個人所有、共同所有、貸与の別
- 固定順、重み付き、重複回避、一巡後重複等の選択規則
- 候補なし時の処理

Family指定は、生成後もPawnが不可視の「武器枠」「防具枠」「防具ポイント」を所有するという意味ではない。開始初期化中に明示候補から具体的な`Thing`へ解決し、以後はそのThingを装着、所持、保管、修理、喪失する。セーブ・ロードで再抽選しない。装備ポイントはFamily間の予算・配備量を比較する計画値であり、Kombinat在庫、通貨、Recipe入力、資産価値ではない。

α開始はXML／Defで具体的な開始装備を指定する。装備ファミリー、候補解決、Fallback診断はβの実装対象とする。βで両方式を併用する場合、一件以上の人物固有または共同体固有の具体指定と、武器または防具を含む一件以上のFamily指定を持たせる。任意の全Stat・全Recipe・全MOD装備を評価する汎用最適化器は作らない。

## 8.5 初期Kombinat口座

標準団は、共同体用の一つの同盟通貨口座を持つ。

Account IDの具体形式はKombinat v4の実装fixtureで決める。少なくとも安定した`expeditionId`から一意に解決でき、翻訳名、Pawn名、Map座標へ依存させない。

Cell、エネルギー結晶、構造材、保守資材、弾薬結晶の五つを含む初期物資は実ThingとしてScenarioまたは開始Profileから生成し、共同在庫へ配置する。同盟通貨だけをAccount初期残高として設定する。栄養／糧食を含める場合は、動物、来訪者、救援、交易、文化的な料理のための物資であり、シオン自身の生理的生存資源ではない。物資数量と通貨残高はコードへ直書きせず、0を許す場合も欠落とは区別する。

人口、労働、研究、団結、名声、支援可能性を残高へ入れない。

同盟通貨は標準団の共同事業用残高であり、団員全員の個人資産を共同所有へ移したものではない。交易、契約報酬、購入、外部サービスの決済に使い、名声、本国への忠誠、Red Star支援資格へ変換しない。RimWorldのSilverとの為替、個人口座、現金・証票、初期通貨量は実装・調整事項とする。

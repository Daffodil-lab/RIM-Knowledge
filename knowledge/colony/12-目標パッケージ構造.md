# 12. 目標パッケージ構造

CoreはRimWorld 1.6、Royalty、Ideology、Biotech、Anomaly、Odysseyを必須とする。次の`About.xml`は5DLCのpackageIdを`modDependencies`へ列挙し、DLCなしの縮退構成を提供しない。現行の独立`Kombinat/`パッケージは移行元なので、このCore製品依存を単独Aboutへ先行して偽装しない。

```text
ShionCore/
├─ About/
│  └─ About.xml
├─ Assemblies/
│  ├─ Shion.Core.dll
│  └─ Kombinat Runtime Assembly（名称はK1で決定）
├─ Defs/
│  ├─ Core/
│  │  ├─ Scenarios/
│  │  ├─ ExpeditionProfiles/
│  │  ├─ Pawns/
│  │  ├─ Bodies/
│  │  ├─ Buildings/
│  │  ├─ Research/
│  │  └─ Quests/
│  └─ Kombinat/
├─ Languages/
│  ├─ Japanese/
│  └─ English/
├─ Textures/
│  └─ Core/
└─ Source/
   ├─ Shion.Core/
   └─ Kombinat Add-on/
```

α版の通常コンテンツへThe HiveとRed Starの固有Def、Scenario、UIを先行作成しない。両者の固有境界とコンテンツはβで必要になった時に作り、αへ空実装を置かない。

Matter Networkはこのツリーへ内包せず、`About.xml`の必須依存にも追加しない。Core独自保管・接続システムをα版からこの製品ツリーへ追加する。詳細ツリーは全体設計が所有する。

Humanoid Alien RacesはCoreの必須依存、Assembly参照、種族型、描画所有者にしない。Shion種族はバニラHuman継承とBiotech Gene／Xenotypeで実装し、詳細は[バニラ優先Shion種族実装境界](/design/52-バニラ優先Shion種族実装境界.md)が所有する。

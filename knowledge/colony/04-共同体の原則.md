# 4. 共同体の原則

## 4.1 独立開拓団の簡易盟約

全独立開拓団に同一憲法を正史化しない。Core α版の標準団だけが共有する簡易盟約として、次を採用する。

1. 各人の人格、身体、名前、記録は本人に属する。
2. 共同設備と共同資源は、現地共同体の維持に用いる。
3. 望まない恒常労働を一人へ固定しない。
4. 救命、緊急防衛、重大な身体変更を除き、本人の同意を先に確認する。
5. 日常業務は担当者が決め、共同体の進路は三人で話し合う。
6. 離脱、帰還、別共同体への参加を人格の裏切りとみなさない。
7. 現地住民を無能力な保護対象としてのみ扱わない。

これは完全な政治制度ではなく、プレイヤー開始文、関係イベント、クエスト判断の基準である。

## 4.2 個人所有と共同所有

| 対象 | 標準的な扱い |
|---|---|
| 人格、身体、名前、私的記録 | 本人の所有 |
| 衣服、装飾、趣味道具 | 個人または合意した共有 |
| Seed設備、発電、工房、共同備蓄 | 開拓団の共同資産 |
| Kombinat台帳残高 | 共同体の論理口座。Pawn所有を意味しない |
| 現地で得た土地 | 支配の自動正当化をしない。ゲーム上の建設領域と正史上の権利を分ける |
| 救援対象の身体・記録 | 開拓団の所有物にならない |

Kombinat v4の安定Account IDは人格の所有者IDではない。非貨幣の同盟Credit Accountを利用する共同体の論理主体を識別する。

## 4.3 指導者

標準団に終身指導者や軍階級を固定しない。RimWorld上のプレイヤー命令はゲーム操作であり、作中の絶対独裁を正史化しない。

必要なら、担当調整者、当番、交渉代表、現場指揮を状況ごとに置く。社交技能の高いPawnが全ての身体・生活・関係を決める制度にしない。

# 21. α版の実装フェーズ

## Phase 0 — 基線固定

- 本書を全体設計と制作ガイドへ接続する。
- Core独自Storage、Network、Endpoint、直接転送、任意排出のα境界を固定する。
- αへ含めるXML／DefとCore Runtimeを一覧化する。
- Kombinat v4追加層の設計fixture、64 bit通貨集計、状態機械、失敗結果を確定する。
- RimWorld 1.6とRoyalty、Ideology、Biotech、Anomaly、Odysseyの公式About、packageId、ロード順を確認する。

## Phase 1 — Core保管・接続基盤

- `About.xml`
- Storage Runtime Assemblyと公開Application境界
- 対象の公式DLCに対する`modDependencies`
- 五つの代表工業資源ThingDefと、同盟通貨Account schema
- 日本語／英語の最低限のキー
- `ThingOwner`、容量、Filter、Network、Endpoint、直接転送、任意排出
- 保存、ロード、停電、接続分断、建築破壊、Map lifecycleの復旧
- RimWorld本体＋対象DLC＋工業fixtureでのロード

## Phase 2 — Kombinat追加層

- Domain、Persistence、Facility、Storage生産予約、発注、多段生産、消費表示、目標在庫、優先度付き流通、通貨を実装する。
- 一つのTerminalで生産、消費、流通を操作し、内部型は診断で確認できる。
- 詳細要件書の全`MUST`とA〜J、追加層監査KX-001〜008とS2-001〜018を通す。

## Phase 3 — 工業fixture

- バニラHumanの試験Pawn
- Coreおよび公式DLCの公開Recipe
- Core独自Storageへ予約・Commitで接続する無バッファ工場DefとFacility Profile
- 保管内容の検索、選択品・指定数・全量排出
- 三段以上のProduction Recipe
- 中断、取消、停電、切断、破壊、ロード復帰
- event駆動索引、Page仮想化、規定規模の性能試験

## Phase 4 — 工業周辺契約

- 工業に必要な研究解禁、エネルギー供給、装備生産の公開接続
- Questと探索からの物資要求契約
- Shion種族、Pawn Foundry、Red Star、The Hiveを参照しないAssembly境界
- 工業基盤完成マイルストーンの全完了条件
- 独自Quest、世界AI、遠隔在庫、空の将来UIは実装しない

## Phase 5 — Shion統合

- `Shion.Core.dll`
- バニラHuman継承とBiotech Gene／XenotypeによるShion種族
- 標準身体、狐耳、狐尾、Portrait、名前、背景、説明
- `ScenarioDef`とVanillaの`ScenPart`
- 三人のShion Pawn生成
- 具体ThingDefによる開始装備
- 最低限の研究、建築、Recipe、翻訳
- 完成済みStorageとKombinatへの公開契約による接続

## Phase 6 — α調整と公開候補

- 初期資源量
- 技能保証
- 脅威と武器
- 翻訳
- UI情報量
- 同一ビルドでの連続プレイ、保存、ロード
- 異なるα／β版のセーブ互換を試験対象にしない

Red StarとThe Hiveの固有コンテンツ、高度な身体Module、装備ファミリー解決、独自救援クエストはα Phase 0〜6へ入れない。

## α公開後のβ候補

- `ShionIndependentFactionProfileDef`の最小境界
- 国家級独立勢力の一Profile
- PMC型組織の一Profile
- 数人団をFactionDefへ水増ししない遭遇・来訪表現
- 組織・拠点ごとに分離したKombinat Accountスコープ
- 同盟本国、Red Star、独立勢力の生成・外交上の分離
- Platform／Interface／Module／Pawn別Configuration
- `シオンShion_Core_β版_Pawn生産保管再生_仕様_v1.md`のPawn FoundryとA〜J受入
- 装備ファミリー、装備ポイント、具体Thing解決
- 生活、救援、善意の不一致
- Red Starの完成プレイループ
- β後期のThe Hive

# 26. 独立開拓団とレッドスターの責務境界

| 軸 | 独立開拓団 | レッドスター |
|---|---|---|
| 成立 | 自発遠征、成長、連邦、分派、契約組織化等 | 本国が正式承認・派遣 |
| 規模 | 数人から国家級まで | 任務ごとに異なり、規模は分類条件ではない |
| 機能 | 生活、研究、交易、救援、国家運営、民間軍事会社型等 | 派遣憲章と正式任務に従う |
| 行動裁量 | 各組織が目的と優先順位を決め、最終責任を負う | 派遣憲章、正式任務、本国からの再指定を受ける |
| 定期支援 | 保証なし | 優れた品質と継続性で接続 |
| 技術・情報支援 | 可能だが保証しない | 専門家、更新情報、任務情報へ優先接続 |
| 輸送・救命 | 現地能力と個別の協力関係に依存 | 回収、後送、救命、輸送への接続が強い |
| 軍事支援 | 標準機能にしない | 任務と緊急度に応じて接続し得る |
| 共同資源 | 現地で育てる | 現地生産と本国支援を組み合わせる |
| 報告・監査 | 各組織の法、契約、内部規則で決める | 任務、在庫、支援物資、活動記録に本国への説明責任を持つ |
| 救援・保護 | 各組織の理念、法、契約、現地判断で決める | 能力と任務範囲に応じた公的な応答義務を持つ |
| 交戦 | 各組織の法、契約、現地判断に従う | 本国の交戦規則と民間保護責務を負う |
| 基盤維持 | 自分たちの生活と生産のために行う | 通信、中継、補給、回収のための公的設備も維持する |
| 関係の性質 | 本国に対する高い自律、国家保証なし | 本国に対する狭い裁量、高い国家保証 |
| コアMODのα版 | 主役 | 実装しない |
| 製品境界 | コアMOD本体 | コアMOD同梱／外部配布を保留 |

レッドスターの支援は、物語上の看板や低確率イベントではない。計画に組み込める補給、専門性、情報、救命・回収能力を持ち、条件を満たした緊急支援は実際に危機を変える。一方、独立団より多い資源だけを与える開始にはしない。任務の割り込み、報告期限、監査可能な用途、救援要請、交戦規則、設備維持が、土地・時間・資源の使い方を継続的に制約する。

参加は同盟による人格・身体の所有を復活させない。構成員は本人の意思で正式任務を受諾するが、受諾した憲章と公的資源への責任を好きな時だけ選んで守ることはできない。責務違反の結果は、信頼、権限、支援優先度、任務関係で表現し、身体没収や人格剥奪へ短絡させない。

したがって、独立開拓団の「支援保証なし」を単なる高難度、レッドスターを低難度にしない。独立開拓団は組織ごとの自律した優先順位、物流、契約、外交を、レッドスターは本国規模の保証と公的任務を中心に遊ぶ。独立勢力が国家級または民間軍事会社型であることは、レッドスターより弱いことも強いことも保証しない。

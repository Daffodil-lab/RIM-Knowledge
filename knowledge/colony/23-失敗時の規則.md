# 23. 失敗時の規則

| 失敗 | 挙動 |
|---|---|
| 公式DLC欠落 | `About.xml`の必須依存として明示し、縮退起動や代替Def生成を行わない |
| Matter Networkが未ロード／非対応版 | Coreは正常に起動する。任意Adapterがある場合だけ、そのAdapterを停止する |
| Core独自保管・接続システムの必須Def／Runtime欠落 | α版Coreの構成不全として起動を停止し、欠落IDを表示する |
| 手動排出先がない | 内容物を保管したまま、塞がっていることを表示する |
| 予約中Thingを手動排出 | 関係ReservationまたはJobを原子的に取消し、成功した時だけ排出する |
| Kombinat追加層の代表工業資源ThingDefまたは通貨schema欠落 | 開始を中止し、v4 schema上の欠落IDを表示 |
| Profile欠落 | セーブを推測で別Profileへ変換しない |
| 身体Module不適合 | 変更を適用せず元の身体構成を維持し、不適合Interfaceを表示 |
| 必須装備Familyの候補なし | Profileの明示Fallbackを使う。なければ部分生成せず開始を停止 |
| 初期残高適用失敗 | 適用済み分を戻し、未初期化のまま停止 |
| Account ID重複 | 新規開始時に再生成。同一ビルドでは自動改名せず診断。α／βの版間移行は対象外 |
| Pawn生成条件不足 | 開始前に再生成または明瞭な警告 |
| UI欠落 | 台帳Runtimeは維持し、開発者診断を可能にする |
| Quest中断 | 未commit予約をrelease |

エラー時にRed Star支援やHive機能を代替起動しない。

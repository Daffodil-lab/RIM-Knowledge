# 1. 文書状態と判断の強さ

本書では、次の状態を区別する。

| 状態 | 意味 |
|---|---|
| **正史採用** | 独立開拓団について世界内の確定事実として扱う |
| **Core α決定** | 最初のプレイ可能版の製品・ゲーム設計として固定する |
| **暫定調整** | Defや数値試験で変更できる。正史ではない |
| **実装予約** | β以後に着手を判断する |
| **保護候補** | 旧資料から回収可能だが未採用 |
| **廃止** | 現テーマまたは製品境界と衝突する |

矛盾時は次の順で解決する。

1. ユーザーの最新決定
2. `シオンShion_正史コア_v2.md`
3. 現行RuntimeコードとDefが示す実装境界
4. 本書
5. 全体設計v2、Kombinat仕様v4、制作ガイド、Matter Network上流保護境界
6. 旧資料

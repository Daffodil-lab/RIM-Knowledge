# 18. 独立状態のUI

複雑な外交画面をα版へ作らない。開始情報または簡易情報カードで次を示す。

```text
立場: 独立開拓団
正規指揮系統: なし
保証された本国支援: なし
共同資源口座: 利用可能
現地方針: プレイヤー共同体が決定
```

「本国から孤立」「本国と敵対」と表示しない。

通信、支援要請、忠誠、Red Starとの関係を示す数値ゲージは未実装のまま置かない。

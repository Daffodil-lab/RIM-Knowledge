# 確定#148：段2品目のフレーバーテキスト

> 履歴項目です。現行仕様との競合時は、正史コアと現在の仕様概念を優先してください。

[出典: シオン/Shion_コンセプト設計書_v2.md 本文 §16（段2品目一覧）]
**段2（確定#148・同盟旧制式6品目）**

| 型番 | 具体品（現実のモチーフ） | フレーバーテキスト |
|---|---|---|
| CP-1189 木蓮 | チャージ式拳銃 | チャージ式の拳銃。旧式ながら化学火薬式の同格火器を凌駕する威力を持つ。「木蓮」はかつて同盟本国の庭園で愛された花——退役後もその優美な名だけは残された。 |
| CR-1170 木曽 | チャージライフル（バニラのチャージライフルと直接対応） | 同盟正規軍のかつての標準火器。辺境部隊にとっての憧れの一挺。「木曽」は同盟艦隊の巡洋艦にも冠された地名——退役してなお、かつての栄光を纏う。 |
| CL-2240 長沙 | 重量級チャージランス | 重量級のチャージ兵器。単発の威力は凄まじいが取り回しには相応の訓練を要する。「長沙」は幾度も激戦地となった都市の名——この銃もまた幾多の戦線を渡り歩いてきた。 |
| CG-3312 ツングース | 簡易・旧式のコイルガン試作機 | 段3の正式なコイルガンより前に配備されていた簡易・旧式のコイルガン試作機。整備性は劣るが対物阻止力は今なお侮れない。「ツングース」は大爆発の伝説を残す地名——その一撃の破壊力を物語る。 |
| CA-4008 向日葵 | カタフラクト級全身装甲 | 退役した正規軍のカタフラクト級全身装甲。同盟基準では旧式だが辺境基準では最上位の防御力を誇る。「向日葵」はかつて同盟の勲章にも意匠として使われた花——陽を追う花のように、かつての栄光を追い求める装備。 |
| CA-4009 向日葵 | 同ヘルメット | CA-4008と対になるヘルメット。視界確保用のバイザーと最低限の通信機能を内蔵する。同じ「向日葵」の名を冠し一対の装備として運用される。 |
| CS-2215 洛陽 | チャージ式散弾銃 | 散弾の代わりに収束したエネルギー弾を放つ近接制圧火器。旧式ながら化学火薬式の散弾銃を凌駕する制圧力を持つ。「洛陽」はかつて幾度も都となった古都の名——退役後もその重厚な響きだけは残された。 |
| CC-1325 桔梗 | チャージ式短機関銃/PDW | 小型で取り回しに優れるチャージ式近接戦闘用火器。「桔梗」はかつて同盟本国で親しまれた花の名——控えめながら確かな存在感を持つ、その花に似た一挺。 |
| CM-4410 Байкал | チャージ式機関銃 | 持続射撃能力を大幅に高めたチャージ式の機関銃。旧式ながら化学火薬式の同格火器を凌駕する制圧力を誇る。「バイカル」は世界最深の湖の名——尽きることのない弾幕を、その底知れぬ深さになぞらえた。 |
| CGL-3120 牡丹 | チャージ式擲弾発射器 | エネルギー弾頭を連続して撃ち出す擲弾発射器。着弾すれば牡丹の花が咲くように爆発が広がる。「牡丹」は"花の王"と称された花の名——退役後もその華やかな爆発だけは変わらない。 |
| CF-1450 彼岸花 | チャージ式熱線放射器 | 燃料噴射に頼らず熱線そのものを放射する旧式の熱線兵器。整備性は劣るが威力は今なお侮れない。「彼岸花」は"死者の花"とも呼ばれる赤い花の名——焼き尽くす炎の色をその花に重ねた。 |
| RG-5510 阿蘇 | 簡易・旧式のレールガン狙撃/精密射撃モデル | 段3の正式なコイルガンより前に配備されていた簡易・旧式のレールガン狙撃モデル。長射程・高初速で、旧式ながら精密射撃の要として今なお運用される。「阿蘇」は日本有数の火山の名——その内に秘めた圧力を、加速するレールの一撃になぞらえた。 |
| RG-6620 Урал | 簡易・旧式の重レールガン対物モデル | 対物ライフル級の破壊力を持つ簡易・旧式の重レールガン。整備は困難だが装甲目標への貫徹力は今なお侮れない。「ウラル」はロシアを東西に分かつ大山脈の名——その巨大さと重さを名に刻む。 |

**注記**：段2の6品目は上記のГвоздика/Незабудка会話形式を**意図的に適用していない**——確定#145のとおり段2「同盟旧制式装備」はDiaspora社（開拓者有志の同人活動）の商品ではなく、退役した同盟正規軍からの払い下げ品であるため、Diaspora社の商品カタログという体裁とは無関係（Diaspora社が扱わない他社/他組織の製品というだけで、フレーバーテキスト自体は既存のまま据え置く）。

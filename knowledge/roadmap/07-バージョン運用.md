# 7. バージョン運用

| バージョン帯 | 意味 |
|---|---|
| `0.0.x` | α以前の内部検証ビルド。公開候補には使用しない |
| `0.1.x`〜`0.4.x` | α。最低限遊べる最初の公開候補。版間セーブ互換なし |
| `0.5.x`〜`0.9.x` | β。CoreとRed Starを完成させる公開開発版。版間セーブ互換なし |
| `1.0.0` | Core MODとRed Starの完成宣言を伴う最初の安定版 |
| `1.x` | 互換を守る追加・改善 |

バージョン番号だけで品質を主張しない。各版は本書の完了条件と検証記録を伴う。

## 7.1 セーブ互換の開始点

- α／βでも、同一ビルド内のセーブとロード、途中状態の復元、終了状態の冪等性は必須である。
- `0.x`の異なる版同士では、セーブ互換、Migration、旧DefName、旧Scribeキー、旧APIの維持を要求しない。
- α／βの変更で既存セーブを読み込めなくなっても、それだけでリリース不合格にしない。
- 互換コードを先に積み上げて最終schemaを拘束しない。
- `1.0.0`で維持対象のdataVersionと公開識別子を固定し、以後の互換・移行責任を開始する。

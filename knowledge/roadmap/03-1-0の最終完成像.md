# 3. 1.0の最終完成像

## 3.1 製品構造

最終的なCoreは、少なくとも次を一つの製品として成立させる。

```text
Shion Race: Core
├─ Base
│  ├─ シオン種族・人格・身体
│  ├─ Pawn Foundry・個体登録・Clone・無料保管・低コスト再生
│  ├─ 独立開拓団のプレイヤー開始
│  ├─ 独立勢力の派閥・外交
│  ├─ 技術・研究・装備
│  ├─ 日常・文化・救援・物語
│  └─ UI・翻訳・保存・互換
├─ Core独自保管・接続システム
│  └─ Network・Controller相当・Interface・IO・実Thing Storage・保存・復旧
├─ Kombinat Add-on
│  ├─ 無バッファFactory／Storage生産予約
│  ├─ 発注・多段生産計画
│  ├─ 生産・消費・流通の追加UI
│  ├─ 同盟通貨・交易・契約
│  └─ Core／Red Star／Pawn Foundry Adapter
└─ The Hive
   └─ 後期に実装する任意起動モジュール
```

Red Starは、Core同梱の任意モジュールまたはCore前提の外部拡張のどちらかへ、β期間中に製品境界を確定する。どちらを選んでも、Coreの通常開始と独立勢力はRed Starを必須としない。

## 3.2 1.0で完成している主要領域

| 領域 | 1.0の完成状態 |
|---|---|
| 種族 | シオンが独立人格の製造人類として生成、表示、負傷、修復、死亡、保存される |
| 身体 | 共通の工業規格と交換可能なInterfaceを持つ狐娘型の標準身体があり、PawnごとのModule、調整、外装、履歴によって一点物の構成になる |
| Pawn生産・再生 | 適合するランダムPawn、既定個体、プレイヤー設計個体、登録個体、Cloneを反復生産でき、生存Pawnを無料保管し、負傷・遺体・登録個体を低コストで回復できる |
| プレイヤー開始 | 数人規模の独立開拓団が、生活、工業、交易、救援を継続できる |
| 独立勢力 | 小集団、拠点網、国家級勢力、PMC型組織を同一陣営へ潰さず表現できる |
| 派閥・外交 | 独立勢力との交易、協力、契約、競争、対立が機能する |
| Core独自保管・接続 | Network識別、接続、実Thingの保管・検索・入出庫、容量、電力・エネルギー、UI、保存、破壊・Map遷移・復旧をCoreが所有し、Matter Networkなしで機能する |
| Kombinat | Core独自保管・接続システムの入力予約・出力容量予約・生産Commitへ接続するFacility、通貨Account、具体発注、依存計画、Production Job／Batch、目標在庫、消費表示、流通優先度、統合Terminal、保存、移行が機能する |
| 同盟通貨 | 契約、報酬、購入、組織間決済へ使え、名声や生存権と混同されない |
| 技術 | 通常工学、同盟標準技術、イェツィラーの三層が研究と利用で区別される |
| ソフェル | 一般利用者と異なる専門性を持ち、万能解決装置にならない |
| 生活・文化 | 料理、祭り、趣味、身体装飾、工芸、動物との暮らしを早期から遊べる |
| 救援・物語 | 善意ある目的、実際の成功、善の定義の不一致、当事者証言、局所調整を遊べる |
| 戦闘・装備 | 種族の能力と制約を示す装備群があり、具体品指定と作者定義の装備ファミリーを併用でき、Family指定は具体Thingへ解決され、補給と修理が工業へ接続する |
| 車輌・動物 | 車輌を主力輸送、改良動物を救難・警戒・生態系・文化・愛玩の担い手として使える |
| Red Star | 優れた支援と正式責務のプレイループが完成し、選択した製品境界で配布できる |
| The Hive | 通常社会から隔離された任意開始・任意機能として動き、上位進化に見えない |
| UI・翻訳 | 日本語・英語で現在値、理由、結果を説明し、未実装機能を表示しない |
| 品質 | 新規開始、長期セーブ、ロード、更新移行、性能、エラー診断が再現可能に検証される |

## 3.3 最終完成に不要なもの

1.0は次を要求しない。

- 旧46MOD構想の全復活
- 全惑星、全巨大建造物、全戦役の実装
- 数千件のバックストーリー
- 全身体形態と全装備案
- イェツィラーの完全な術式一覧
- 魂と人格複製の形而上学的な最終回答
- 全外部MODへの互換Adapter

量ではなく、主要領域が代表的な内容と拡張可能な基盤を持つことを完成条件にする。

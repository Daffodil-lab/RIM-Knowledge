# C-0002 匿名ソフェルのTierとQuality

## 判定

旧人物資料は`Tier +12`と`Quality 1.10–1.20`を確定値として扱う。現行正史と全体設計は、身体基盤のTier、Quality、スロット数、改造点を保護された未確定または実装予約としている。

値の正誤を固定せず、人物像と実装値を分離する。したがって`hard-conflict`ではなく、旧案と現行設計の`overhaul-divergence`として解消する。

## 処置

- 人物像は[匿名のソフェル](/characters/anonymous-sofer/00-現行正史.md)へ統合した。
- TierとQualityを含む具体値は[実装予約](/characters/anonymous-sofer/53-実装予約.md)へ分離した。
- 旧52項目は`authority: historical`へ移し、現行正史や実装確定値として引用しない。
- 身体体系の決定後、人物の相対的な能力像を保ったまま数値を再設計する。

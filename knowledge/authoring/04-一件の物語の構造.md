# 4. 一件の物語の構造

テーマを扱うクエスト、バックストーリー、イベントは、原則として次の五段階から必要な部分を使う。

1. **善意ある目的**：誰を何から救おうとしているかを具体化する。
2. **実際の成功**：治療、救出、復活、再建、供給等を本当に成立させる。
3. **善の定義の不一致**：成功後に、身体、呼び名、土地、関係、時間、所属等の差が現れる。
4. **当事者の証言**：道徳解説ではなく、一人の経験として差を示す。
5. **任意の調整**：同意確認、名称保存、追加工程、別の帰属等を選べる場合がある。

全ての物語へ五段階を詰め込まない。理想郷の日常、趣味、戦闘、工業、動物との暮らしだけを扱う内容も必要である。

一つのクエストで中心問題を一つだけ扱う。帝国史、人格同一性、同化、政治制度、The Hive等を、一件の導入でまとめて説明しない。

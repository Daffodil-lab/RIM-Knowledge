# 18. 強い七つの対

シオン固有の世界感は、次の七つの対によって統一する。これらはどちらか一方を選ぶ二者択一ではない。**両側が同時に真であること**によって、シオンらしい緊張と奥行きが生まれる。

| 対 | 同時に成立すること | 片側だけにした場合の崩れ |
|---|---|---|
| **聖なる秩序 ↔ 俗世の自由** | 帝国の宗教・法・倫理・技術は聖なる秩序に統合され、同盟はその遺産を世俗的な自由と生活へ使い直す | 帝国性を消すと由来のない日用品になり、同盟を宗教化すると時代差が消える |
| **古い手触り ↔ 超未来の結果** | 白陶器、真鍮、紙、布、時計、儀礼、消えない20～21世紀の生活記憶から、人格再製造、因果操作、恒星規模の結果が出る | 古さだけでは懐古趣味になり、未来性だけでは汎用近未来SFになる |
| **本物の理想郷 ↔ 未完成の辺境** | 本国の自由、豊かさ、安全は本物だが、遠征先では産業、補給、修理、関係を一から築く | 本国を偽物にすると普通のディストピアになり、辺境を消すとゲーム上の営みがなくなる |
| **純粋な善意 ↔ 善を定義する傲慢** | 救援は本気で実際に成功するが、圧倒的な大国は何を善い結果とするかまで先に決められる | 善意を消すと偽善国家になり、傲慢を消すと力の非対称性が消える |
| **絶対的な技術確信 ↔ 物質と選択の制約** | シオンは自らの技術が実現できることを強く確信するが、全知全能ではなく、資源、設備、保守、失われた知識、優先順位、対価、人間による判断と責任を持つ | 確信を消すと超文明らしさがなくなり、制約と担い手を消すと万能装置になる |
| **製造された共通身体 ↔ 代替不能な人類個人** | 全通常シオンが無性の狐娘型規格を共有しても、一人ずつ別の人格、身体構成、履歴、美意識を持ち、文化と自己認識によって人類である | 共通規格だけでは量産人形になり、個体性だけでは製造人類という文明基盤が消える |
| **人類統一 ↔ そこから始まる歴史** | 人類統一は巨大な理想と到達点だが、エンディングでも歴史の終焉でもなく、未知の時代の出発点である | 統一を消すと文明的野心が弱まり、最終回答にすると「全てはまだ始まったばかり」が失われる |

## 七対を横断する副対

次の対は重要だが、独立した第八、第九の軸へ増やさない。七対が具体的な人物、物、時代へ現れた形として扱う。

- **保守 ↔ 革新**：第1対と第2対の横断形。帝国の人材、規格、建築、使命を保ちつつ、所有、生活、正統性、用途を革命的に変える。
- **優れた機械 ↔ 人間が中心**：第5対と第6対の横断形。自動機械は極めて優秀でも、意味のある判断、責任、仕事、軍事、産業の中心からシオンを消さない。
- **可愛い ↔ 凛々しい**：第6対の視覚形。どちらも通常の造形幅であり、性別や人格価値を示さない。
- **20～21世紀の記憶 ↔ 遠未来**：第2対の文化形。生活様式、衣服、娯楽、道具の記憶を再解釈し、技術水準だけはその時代へ閉じ込めない。

## 三層との役割分担

[世界観の統一軸](/authoring/13-世界観の統一軸.md)にある帝国の基層、同盟の暮らし、辺境の手入れは、**画面や場面へ何を重ねるか**を決める。

七つの対は、**その設定がなぜシオン固有なのか**を判定する。三層は視覚・生活・時代の構成、七つの対は主題上の緊張を所有する。

## 適用規則

一つのアイテム、人物、建築、クエスト、バックストーリーへ七対全てを詰め込まない。

1. 主となる対を一つ選ぶ。
2. 必要なら別の対の痕跡を一つ置く。
3. 主となる対の両側が、説明、外見、挙動、結果のいずれかで実在することを確認する。
4. 七対を七派閥、七Tier、七属性、七つのゲームゲージへ変換しない。

適用例:

- 帝国由来の拳銃：**古い手触り ↔ 超未来の結果**を主とし、修理や弾薬で**技術確信 ↔ 制約**を添える。
- 狐娘型の人物：**共通身体 ↔ 人類個人**を主とし、可愛い、凛々しい、古風、実務的等の個体差を置く。
- 救援クエスト：**純粋な善意 ↔ 善を定義する傲慢**を主とし、本国と辺境の資源差を添える。
- ゲームクリア：共同体の野心を実現したうえで、**人類統一 ↔ そこから始まる歴史**を閉じない。

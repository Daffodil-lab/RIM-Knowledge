# 10. 廃止・降格された旧要素

旧資料の大規模な構想は、存在を忘れるのではなく、現在の状態を明示して保持する。

| 旧要素 | 現在の状態 |
|---|---|
| 「時計仕掛け」「有機機械」「時計仕掛けの狐人形」を固定三分類とする | 固定分類として廃止。個別の身体・素材案としてのみ再審査可能 |
| 狐人形を自由意志・認知を削った通常身体とする | 廃止。扱う場合は危険な特殊処置として別途審査 |
| 全シオンが自由にイェツィラーを記述できる | 廃止 |
| イェツィラーに触れる者全員をソフェルとする | 廃止 |
| 同盟標準技術とイェツィラーを同一視する | 廃止 |
| 同盟を通常はグリッターワールド級へ固定する | 廃止。既存技術Tierで能力上限を固定しない |
| 狐娘型でない通常シオンを、同格の標準形態として並存させる | 廃止。通常シオンはかなり初期から皆、狐娘型の共有身体を使う |
| 狐娘型を生物学的な女性とし、人間型の内臓、生殖、生理現象を与える | 廃止。通常シオンの身体は中性・無性の非生物的な機械身体である |
| 非人型を上位進化・真の姿とする | 禁止 |
| The Hiveを通常シオンの代表・完成形とする | 禁止。後期にCoreへ同梱しても専用開始・研究・クエストで隔離する |
| Kombinatを独立購読MODとして維持する | 廃止。Core常駐Runtimeへ統合する。現行Assembly・APIはK1監査の参考であり、α実装での無条件な再利用義務ではない |
| The HiveをCore依存の外部購読拡張として維持する | 廃止。Core同梱の任意起動モジュールへ統合するが、実装は後期へ延期する |
| 栄誉や発言力の偏りを、本国が偽物の理想郷である証拠とする | 廃止 |
| 実在指導者名の勲章 | 廃止。使用する場合は独自名へ変更 |
| 実在作戦・被害を娯楽シナリオへ直接対応させる | 廃止 |
| 「ミチューリン農芸公社」を現行組織名とする | 廃止。[農芸公社](/world/21-農芸公社.md)という共同体類型へ改稿 |
| 「サミズダート」を現行市民組織名とする | 旧称へ降格。[余白記録網](/world/20-余白記録網.md)へ独自化 |
| Diaspora系を一つの固定組織分類とする | 廃止。独立勢力の一般分類へ統合 |
| 帝国人またはシオンを作中で「アルコテック種族」と呼ぶ | 廃止。能力比較に限る作者用語とし、作中では帝国人、シオンと呼ぶ |
| 文学作品名を全公開MODの正式名として固定する | 歴史資料へ降格。公開名は個別に再審査 |
| 46個の公開MOD構成 | 現行製品計画ではない。少数の大分類へ再編する候補資料 |
| 4,000バックストーリーを出荷目標とする | 廃止。旧カタログは作者用候補集として保持 |
| 120惑星・19巨大建造物をプレイヤーの前提知識にする | 禁止。必要なものだけ個別に提示 |
| 60／120惑星または26惑星名を一括で正史化する | 不採用。トヴェルジとクピナ以外は一件ずつ再採用 |

廃止された件数、分類、名称も、旧資料を読む際の誤採用防止に必要な情報である。新しい構想が偶然同じ数へ到達しても、旧計画が自動復活したことにはならない。

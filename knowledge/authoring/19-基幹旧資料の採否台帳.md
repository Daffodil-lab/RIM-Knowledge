# 19. 基幹旧資料の採否台帳

旧資料は文書全体を一括採用しない。一つの文書に正史、要改稿、実装値、廃止要素が混在するため、概念ごとに現在の所有者へ移す。

## 判定区分

| 区分 | 処理 |
|---|---|
| 採用 | 現在の統一軸と矛盾せず、正史所有者または採用済みカタログへ接続する |
| 改稿採用 | 中心となる人物、用途、出来事、感情を残し、旧身体分類、旧政治名、旧技術上限等を現在の正史へ合わせる |
| 設定クラス限定 | 存在、名称候補、用途、歴史、外見、フレーバーだけを採用し、数値と実装完成を意味させない |
| 実装予約 | Def、クラス、性能、素材数、工数、製造時間、Tier、Quality、出現率等を担当実装まで固定しない |
| 廃止 | 現在の正史境界と両立せず、歴史資料としてのみ保持する |
| 新規補完 | 旧資料に不足し、現在の統一軸を成立させるため新しい正史所有者を追加する |

## 基幹概念の判定

### 採用

- 帝国と同盟は、善き世界を実装しようとする同一文明の二形態である。
- 帝国最盛期の善政と繁栄、末期帝国の圧政はどちらも実在する。
- 同盟本国の自由、豊かさ、安全は偽物ではない。
- シオンは製造身体を持つ独立人格であり、身体と製造手段を自己所有する。
- 身体再製造、人格記録、復活、Clone、休眠保管は工業として反復できる。
- 同盟の救援は本気で、多くの場合は実際に成功する。
- 超文明の能力と、辺境での修理、補給、産業化は両立する。
- ソフェルは全シオンの種族特性ではなく、帝国由来の専門職である。
- 古い道具、料理、動物、工芸、祭り、趣味を自由な生活として楽しむ。

### 改稿採用

- 狐娘型は選択可能な一形態ではなく、通常シオンがかなり初期から共有する標準外形へ改稿した。
- 狐娘型を生物学的女性とする旧解釈を廃止し、中性・無性の非生理的な機械身体へ改稿した。
- 人間型の内臓、食事、睡眠、生殖等をシオンの生存要件とする記述は、感覚文化、整備、歓待、他種族支援へ改稿した。
- 巨体、車輪体、動物型、四腕型等を通常シオンの並行標準形態とする記述は、狐娘型内部の重量、機能、感覚、調整差または外部住民へ改稿する。
- 宗教的SFは現代同盟全体ではなく、帝国時代と帝国由来の人物、制度、技術、遺物へ限定した。
- 人類統一は歴史の終焉ではなく、統一後の未知へ入る出発点へ改稿した。
- 20～21世紀の生活記憶は、そのまま保存された現代文化ではなく、同盟が再解釈したレトロ文化として扱う。

### 設定クラス限定

- 装備の分類、カタログ名、用途、使用者、歴史層、外見、フレーバー
- 身体Moduleの用途、文化的位置、外装方向
- 組織、共同体、惑星、施設、動物、植物の名称候補と概念核
- 帝国遺物、儀礼、衣装、秘文字の視覚・文化的方向
- 遠征共同体の野心と、それに必要な産業分野

固有名の存在を採用しても、旧資料に並ぶ全組織、全惑星、全施設を一括正史化しない。一件ごとに所有者、時代、所属、公開価値を確認する。

### 実装予約

- 武器の射程、命中率、ダメージ、貫通、発射間隔、装弾数
- 身体、Module、装備の素材、耐久、重量、価格、品質
- Recipe、材料数、工数、製造時間、研究、技能条件
- Tier、Quality、改造点、スロット数、全特性表
- Red Star支援の頻度、数量、到着時間、責務判定
- 人口比率、組織数、惑星数、バックストーリー出荷数
- 勝利条件の必要量、建築数、研究費、所要時間
- ゲームエンジン上の性別、Needs、当たり判定、描画倍率等のAdapter値

### 廃止

- 「時計仕掛け」「有機機械」「狐人形」を通常シオンの固定三種族とする。
- 非狐型の通常シオンを同格の標準形態として並存させる。
- 狐娘型を生物学的女性、人間型内臓、生殖、生理へ結び付ける。
- The Hiveを通常シオンの完成形、進化先、秘密の真実とする。
- 同盟を通常はグリッターワールド級という既存Tierへ固定する。
- 全シオンが自由にイェツィラーを記述できる。
- 同盟本国の幸福を洗脳、宣伝、秘密搾取による偽物とする。
- 同盟全体を帝国と同じ宗教国家として扱う。
- 人類統一、同化、超越、宇宙征服を唯一の最終エンディングとする。
- 旧46MOD、120惑星、19巨大建造物、4,000バックストーリー等の数量目標を自動復活させる。
- 実在指導者、実在作戦、外部作品の固有名を公開正史へ直接使用する。

## 新規補完した所有者

旧資料の核だけでは現在の統一軸を明示できないため、次を新規正史として補完した。

- 同盟の三条約構造と正式名称
- 遠征共同体の野心と産業化
- 通常シオンが初期から共有する狐娘型
- 中性・無性で人間型内臓を持たない機械身体
- 文化、思想、歴史、自己認識による人類性
- 狐耳と身体の標準的な寸法、人間耳の不在
- 宗教的SFの帝国由来境界
- 可愛い造形と凛々しい造形の並存
- 全てはまだ始まったばかりという歴史の開放性
- 世界観を判定する強い七つの対
- 設定クラスと実装値の分離
- バックストーリーの形成期・熟達期と文化継承語彙
- バックストーリー設定本文と実装予約の明示的分離

# 6. 媒体別の情報予算

| 媒体 | 原則 |
|---|---|
| MOD紹介文 | 世界の約束を2文、遊びを1文。年表を入れない |
| Thing・Research説明 | 機能を先に書く。新固有語は0～1個。ロアは最後の短文 |
| クエスト導入 | 最初の80～120字で困っている者、目的、失敗時の結果を示す |
| クエスト全体 | 未説明の新固有名詞は原則2個以内。中心問題は一つ |
| バックストーリー | 一人の具体的な出来事。新固有語は原則1個以内 |
| イベント通知 | 観測可能な結果を普通語で書く。文明史や道徳判定を講義しない |
| UI・台帳 | 数える項目と数えない項目で価値観を示す。作者の結論を表示しない |
| 身体 | 本人の用途・感覚・外見を先に書く。規格名やTierを人格説明にしない |
| 武器・防具カタログ | 設定クラス、用途、使用感、フレーバーを書く。実在国・実銃・制式番号を正史説明へ出さない |
| 武器・防具のStat表示 | 射程、性能、素材、工数等は実装値として表示し、フレーバーの正本にしない |
| 開始装備Profile | 物語必須品は具体指定し、多様性が必要な役割枠は作者定義の装備ファミリーを使う。解決後の表示は具体品名にする |

通常プレイで反復する語は、シオン、同盟、本国、Cell、エネルギー、エネルギー結晶、弾薬結晶、ソフェルを中心にする。凝縮真空は廃止語ではなく、エネルギー分野の具体技術へ触れる場面で導入する。追加語は、その場の目的を理解するために必要な時だけ導入する。

# 0. 文書状態の分類

全ての設定、文章、機能案は次のいずれかへ分類する。

| 状態 | 意味 | 使用条件 |
|---|---|---|
| 正史 | 正史コアv2またはユーザーの最新決定で確定 | 世界内事実として使用可能 |
| 保護された未確定 | 正解を固定しないこと自体が設計 | 答えを断定せず、複数の証言や結果だけを示す |
| 実装予約 | 世界観と両立するが、仕様・数値・UIが未決 | 正史化や出荷をせず、担当MODで決定する |
| 廃止 | 現行正史と両立しない、または明示的に撤回 | 歴史説明以外へ再使用しない |
| 歴史資料 | 旧統合資料、旧正本、監査記録、候補集 | 発想源としてのみ使用し、自動採用しない |

単に「WIP」とだけ書かない。未確定にする理由が、保護、実装待ち、再審査、廃止のどれかを明示する。

文書状態とは別に、内容の責務を`setting-class`と`implementation`へ分ける。設定クラスが確定し、実装値だけが未決である場合、項目全体を実装予約にしない。設定クラスは正史または設定カタログとして保持し、未決の数値、素材、Recipe、工数等だけを実装予約へ置く。

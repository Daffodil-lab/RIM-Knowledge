# 参考

参考作品・要素、過去に作成したが放棄された資料、実用水準に満たない資料、現在も再設計の手掛かりになり得る資料をまとめる入口です。参考資料は現行正本、実装確定、出荷決定を所有しません。

## 利用境界

- [参考資料の利用境界](00-%E5%8F%82%E8%80%83%E8%B3%87%E6%96%99%E3%81%AE%E5%88%A9%E7%94%A8%E5%A2%83%E7%95%8C.md) — 参考資料は、現行正本ではないが、調査、比較、発想、再設計の入力として再利用できる可能性を持つ資料である。

- [調査・参照](/research/index.md) — 外部作品、MOD、UI、映像、既知コード等から得た比較・調査記録。

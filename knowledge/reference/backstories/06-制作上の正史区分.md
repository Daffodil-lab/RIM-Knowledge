# 6. 参考資料としての区分

- バックストーリーは全件を実用未達の参考資料として保持する。
- 現在の全838件は`reference_review: reference-only`であり、現状は実用に値せず、参考可能性や再利用可能性も保証しない。
- `reference-only`は比較、失敗分析、将来の再検討のためだけの保管を表し、正史、実装、出荷への採用を表さない。
- `re-audit`は旧稿の出来事、表現、技能根拠を現在の正本を基準に再監査する状態である。
- `candidate`は新しい参考候補であり、出典、権利、内容、再利用価値を確認するまで採用しない。
- SourceModuleは発想と生成条件の所属を表し、外部作品の文章や登場人物を複写するものではない。
- 将来再利用を検討する場合は個別に再審査し、採用する内容だけを現在の正本所有者または担当実装へ移す。バックストーリー自身を正本へ昇格させない。

# バックストーリー

バックストーリーは全件を[参考資料](/reference/index.md)として保持する。現在の全838件は実用に値しないため`reference_review: reference-only`とし、比較、失敗分析、将来の再検討のためだけに保管する。参考可能性や再利用可能性を保証せず、正史採用、実装採用、出荷採用も示さない。

`candidate`は新規の参考候補、`re-audit`は旧稿の再監査対象である。バックストーリーから要素を採用するときは、現在の正史または担当実装の所有者へ必要な内容を移し、採用先を正本とする。

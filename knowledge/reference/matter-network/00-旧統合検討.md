# 旧Matter Network統合検討

Matter Networkとの統合は過去に検討された案件である。現行の製品仕様、要件、試験、ロードマップには使用せず、判断経緯の確認が必要な場合だけ決定履歴と外部調査を参照する。

現行の保管・接続仕様は[Core独自保管・接続システムの実装境界](/design/51-Core独自保管接続システムの実装境界.md)、発注・生産・通貨は[Kombinat中核仕様](/kombinat/core/index.md)が所有する。

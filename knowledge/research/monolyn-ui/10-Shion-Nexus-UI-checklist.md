# 10. Shion Nexus UI checklist

Before Alpha 0.1 release, confirm:

- Core Inspect explains alive/damaged/destroyed state.
- Ledger Inspect shows CVE, capacity, shells, Mercy Stock, Record Integrity, and shutdown state.
- Hangar Inspect shows why Worker output can or cannot happen.
- Worker expiry/death rules are visible somewhere.
- Relay Inspect shows charge state and Core protection effect.
- Mercy Inspect shows required input and output result.
- Every failed action returns a reason.
- No critical status is visible only in research UI.
- No placeholder reads like a broken final system.
- English default text and Japanese text both explain function, not only lore.

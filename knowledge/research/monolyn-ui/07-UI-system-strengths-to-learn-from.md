# 7. UI/system strengths to learn from

Monolyn strengths reported by players/review:

- strong faction identity;
- Tower-centered operation;
- unique resource economy;
- dedicated equipment/codex system;
- mysterious atmosphere;
- custom production path;
- integration of race, infrastructure, equipment, and progression.

Shion Nexus should learn:

- one central identity object is powerful;
- resource, bodies, equipment, and buildings should feel connected;
- custom systems are acceptable if the player can read them;
- atmosphere matters, but readability must win over mystery at the operation layer.

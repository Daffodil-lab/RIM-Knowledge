# 9. Alpha impact

This reference reinforces current Alpha 0.1 rules.

Alpha must keep:

- no custom research UI;
- no large custom UI;
- explicit Terminal Hangar commands;
- Tower Ledger as the readable control surface;
- `NexusBlockReason` for failed actions;
- clear labels and descriptions;
- visible scalar values;
- base-game-only startup with no red errors;
- no complex apparel display dependency;
- no Ideology dependency.

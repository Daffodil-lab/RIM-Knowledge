# 2. Shion Nexus relevance

Fleshbeast Colony remains a structural reference only.

Useful areas to observe:

- colony infrastructure identity;
- central resource feel;
- transformation pacing;
- player readability during base growth;
- how a nonstandard colony system teaches itself;
- balance between buildings, resources, and pawn activity.

Do not copy:

- organic flesh identity;
- gore or body-horror presentation;
- corpse-processing tone;
- visual red/flesh palette;
- Anomaly/Biotech hard dependency;
- heavy simulation patterns if present.

# 9. Final rule

The reference mods prove that strong race/colony mods work best when they are not just pawns with stats. They need a colony-scale operating system and a recognizable visual language.

For Shion Nexus, that operating system is:

> Nexus Core + Tower Ledger + Condensed Vacuum Energy + Terminal Control Capacity + Tower Logistics + Mercy Connection + Named Terminal Records.

Its visual language should be:

> Animated clockwork core, ledger motion, vacuum glow, terminal shell deployment, shield relay pulse, mercy processing, and preserved names.

This is the structure that should define the Plan B Hive Version.

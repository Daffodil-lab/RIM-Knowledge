# 0. Purpose

This document records how three existing RimWorld Workshop mods should be used as structural references for Shion Nexus.

Reference mods:

- Monolyn Race
- Fleshbeast Colony
- Arachnae Swarm 2

These are not direct design targets. Shion Nexus should not copy their identities, lore, names, assets, or exact mechanics. It should extract useful structural patterns and adapt them to the Plan B Hive Version.

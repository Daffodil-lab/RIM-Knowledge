# 1. ロシア・中国系の現代戦闘数理とドローン体系

この資料は、公開されているロシア軍事科学および中国人民解放軍系研究の考え方を、RIMの戦闘評価設計へ翻訳するための外部参考である。数式、国家名、組織名、現実の戦争は正史を所有しない。外部の式をそのまま採用するのではなく、用途、入力、限界を確認してから設計側へ移す。

## ロシア系：COFMと戦闘ポテンシャル

RAND RR-4235は、ロシアの「兵力・手段の相関」COFMを、単純な兵数比ではなく、兵器・編成へ与えた戦闘ポテンシャルと、任務、環境、訓練、士気、指揮、兵站等を用いる作戦計画上の比較として整理している。公開資料から確認できる重要点は、単一の統一式が常に使われるというより、用途と時期によって複数の方法が併存し、その妥当性自体がロシア軍事科学内で議論されてきたことである。

### 特性から兵器ポテンシャルを作る形

RANDが紹介する軍事ポテンシャロメトリの形は、正規化した機能特性 `P_i` を重要度 `a_i` で合成する。

```text
CP = sqrt( sum_i a_i * P_i^2 )
0 <= a_i <= 1
sum_i a_i = 1
```

これは異なる兵器を共通尺度へ置く入口にはなるが、重みを変えると結果が大きく変わり得る。任務と環境から切り離した恒久的な「真の戦闘力」として扱わない。

### 編成の加算とその限界

兵器種 `i` の数を `n_i`、単体ポテンシャルを `P_i` とすれば、編成の単純な入口は次になる。

```text
CP_formation = sum_i n_i * P_i
```

この形は高速な比較に向く一方、異種装備の相互作用、指揮統制、兵站、電子戦、地形を十分に表せない。RANDが紹介する批判でも、編成・複合システムの効果は下位システムの単純合計ではなく、特定の作戦状況に依存するとされる。RIMではこの値を最終勝敗へ直結させず、ネットワークと状態遷移を別に評価する。

### 損耗の基準形

集中して相互に射撃する二集団の基準比較には、Osipov–Lanchester型の平方則を置ける。

```text
dR/dt = - beta * B
dB/dt = - alpha * R
alpha * R^2 - beta * B^2 = constant
```

ただし、現代の分散戦、遮蔽、索敵、射程差、精密誘導、ドローン、電子戦、補給、離脱を一式で表せない。RIMでは「双方が互いを捕捉し、同時に有効射撃を継続できる」局所状態の比較基準に限る。

## 中国人民解放軍系：体系効率とキルチェーン

中国の公開軍事工学研究では、単体兵器の性能より、偵察・指揮・射撃・保障を接続した装備体系、作戦体系、キルチェーンの能力を評価する研究が多い。これは特定国家への固定ボーナスではなく、ネットワーク化された戦闘を記述する方法として参照する。

### ADCモデル

古典的ADCモデルは、可用性 `A`、信頼性・持続性 `D`、固有能力 `C` の積で体系効率 `E` を置く。

```text
E = A * D * C
```

改良研究では、任務適合 `M` や指揮・保障等の要素 `G` を追加する例がある。

```text
E = A * D * C * M * G
```

積形式は一要素の重大な欠落が全体を強く制限する点を示せるが、要素の独立性を仮定しやすく、指標定義によって二重計上も起きる。RIMでは一部を論理ゲート、一部を確率、一部を状態として分離する。

### キルチェーン能力

公開研究に見られる一般形では、任務種 `i` の経路 `K_i` を構成するノードの能力 `cp(v_n)` を合成し、経路と任務を重み付けする。

```text
C_K = (1 / (k - 1)) * product_n cp(v_n)^(1 / lambda)
C(G) = sum_i omega_i * sum_(K in K_i) C_K
```

表記と正規化方法は論文ごとに異なるが、要点は経路上の弱い接続が任務全体を制限し、複数経路が冗長性を作ることである。ノード除去前後の差から重要度を測る形も使える。

```text
I(v) = ( C(G) - C(G without v) ) / C(G)
```

この考え方は、指揮所、通信中継、偵察ドローン、電子戦装置、射撃部隊、補給拠点のどこを失うと任務が崩れるかを説明できる。

### 目標割当

攻撃手段 `i` を目標 `j` へ割り当てる二値変数を `b_ij` とする最小形は次になる。

```text
b_ij in {0,1}
sum_i b_ij <= target_capacity_j
sum_j cost_ij * b_ij <= resource_i
```

目的関数には期待損害、任務価値、時間、弾薬消費、被探知危険、民間被害等を置ける。RIMでは自動最適化が政治目的とプレイヤー判断を上書きしないよう、交戦規則と任務優先を制約条件として先に置く。

## ドローン戦への含意

2024年のロシア語圏UAV研究、中国の無人群・キルチェーン研究、近年の実戦から共通して得られる設計上の含意は、無人機を機体単体で評価しないことである。

- 偵察ドローンと砲兵・誘導兵器の接続は、発見から射撃までの時間を縮める。
- FPV・徘徊型・投下型は安価な攻撃機会を増やすが、操縦者、通信、弾頭、発進地点、天候、目標識別へ依存する。
- 電子戦は通信・航法を妨害するが、周波数変更、中継、自律、光学、慣性、光ファイバー等の適応で効果が変わる。
- 無人群は機数だけでなく、同時管制、衝突回避、任務配分、通信負荷、回収・補充によって上限を持つ。
- 対無人機は妨害だけでなく、探知、識別、欺瞞、遮蔽、機関砲・迎撃弾・迎撃機、発進拠点攻撃を組み合わせる。
- 安価な機体の損耗を許容できても、熟練操縦者、電磁情報、通信中継、弾頭、電池、製造設備は別の希少資源になり得る。

したがってゲームでは、「ドローン攻撃力」一値より、任務連鎖の成立、同時運用上限、電磁環境、補充周期、敵の適応を追跡する方が妥当である。

## 時点と限界

RAND RR-4235は2020年刊行であり、ロシアのCOFM思想と方法論を理解する基礎資料として有用だが、2022年以後のウクライナ戦争で急速に変化したFPV、徘徊型弾薬、対無人機、光ファイバー誘導等を網羅しない。後発の公開研究と実戦観察で補う必要がある。

中国側の公開論文は工学的評価法と概念研究を示すが、人民解放軍の実際の全装備、非公開アルゴリズム、戦時運用成績を証明しない。公開研究に現れる式を、実戦で検証済みの公式単一モデルとは呼ばない。

どのモデルも、入力値の由来、重み、独立性、データ不足、敵の適応へ敏感である。出力は比較と説明に使い、精密な数字に見えることを正確さの証明にしない。

## RIM設計への採用境界

- 戦闘ポテンシャルは任務別の基礎比較へ限定する。
- 最終戦果は、可用性、任務連鎖、状態遷移、補充、観測誤差を加えて裁定する。
- ドローンと電子戦を独立した万能倍率にせず、センサー、接続、攻撃、妨害、補給のノードとして扱う。
- ロシア式・中国式という陣営固有の数値補正を作らない。
- 現実の国家、戦争、部隊名を、そのまま賛美的な正史または娯楽的シナリオへ移さない。
- RIM固有の数式とゲーム状態は[体系戦闘評価モデル](/design/59-体系戦闘評価モデル.md)が所有する。

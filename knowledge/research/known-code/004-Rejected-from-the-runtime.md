# Rejected from the runtime

- A monolithic Core building Comp as the owner of resource truth.
- Separate aggregate reservation totals without reservation records.
- VEF PipeSystem as the canonical resource ledger.
- Per-tick global scans or hidden worker Pawns.
- Direct state mutation by UI or extensions.
- Core Persona, Projection, game-over anchor, stealth, race, body, and HAR
  content; these belong to CoreMOD/The Hive, not Kombinat.
- Any code or assets from third-party reference mods.

# 8. Relationship to other alpha buildings

The Core Tower must be visually more important than every other alpha building.

| Building | Relative visual weight |
| --- | --- |
| Nexus Core | tallest/heaviest silhouette, central aperture, most symbolic. |
| Tower Ledger | flatter, readable plates, cyan lines. |
| Terminal Hangar | utilitarian bay, shell storage, no symbolic crown. |
| Shield Relay | smaller pylon/fins, thin arc, defensive role. |
| Mercy Connection | basin/cradle, gentle white light. |

If a player sees all buildings together, the Core must be the obvious center.

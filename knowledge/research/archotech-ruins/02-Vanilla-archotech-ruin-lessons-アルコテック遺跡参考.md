# 2. Vanilla archotech ruin lessons

The supplied reference images suggest these useful visual traits:

- large simple block masses;
- thick black outlines;
- muted gray or dark stone/metal support shapes;
- pale interior faces or slabs;
- only a few glowing lines;
- minimal small detail;
- readable top-down silhouette;
- ancient machine feel rather than modern circuit board;
- asymmetric but balanced silhouette;
- object identity readable from far zoom.

Shion Nexus should learn the silhouette discipline, not copy exact shapes.

# 7. Per-state Core visual rules

| State | Visual direction |
| --- | --- |
| Dormant | dark lens, closed tower face, no ledger line except faint mark. |
| Awake | central blue-violet aperture visible, one cyan control line lit. |
| Low CVE | blue-violet shrinks to a small point, cyan ring fades. |
| Damaged | ceramic cracks, amber warning notch, unstable aperture. |
| Permanent shutdown | ash-gray shell, dead dark lens, small red-orange fracture mark. |

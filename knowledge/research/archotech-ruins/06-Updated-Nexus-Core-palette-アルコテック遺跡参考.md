# 6. Updated Nexus Core palette

Core Tower should use:

- dominant: Enamel White / Pale Ceramic Ivory;
- lower support: Blue-Black Navy or dark gray support block;
- aperture: Void Black with deep Vacuum Blue-Violet center;
- control line: small Pale Cyan channel;
- mechanism: small Muted Brass seams;
- warning: Amber notch only when blocked/damaged;
- failure: Red-Orange fracture only for permanent shutdown or critical Core danger.

The Core should not be cyan-dominant. Cyan belongs mainly to Ledger/control. The Core should be white/void/blue-violet dominant.

# 9. Art prompt direction, not image generation request

Use this as future asset guidance:

```text
Top-down RimWorld-style 3x3 building sprite, Nexus Core Tower for a clockwork fox hive, vanilla archotech ruin-inspired silhouette, simple heavy monolith/tower form, thick dark outline, dark blue-black base, pale ceramic white tower body, void-black central aperture with deep blue-violet core glow, one subtle pale-cyan ledger line, small muted brass seams, two restrained fox-ear-like crown fins, ancient machine core not religious tower, not circuit board, not battery, not generator, readable at small RimWorld scale, static state variants.
```

```text
RimWorld風の真上視点3x3建築スプライト。時計仕掛け狐ハイブのNexus Core Tower。バニラのアルコテック遺跡に馴染む、単純で重い塔/モノリス形状。太い暗色アウトライン、暗い黒紺の基壇、白い陶器質の塔本体、void-blackの中央開口部、深い青紫のCVE光、控えめな淡いシアンの台帳線、小さな鈍い真鍮継ぎ目、狐耳を思わせる控えめな冠フィン。宗教塔ではない。基板ではない。電池でも発電機でもない。小さいRimWorld表示で読める静的状態差分向け。
```

# kombinat-ui-references

## 位置づけ

ユーザー提供の動画とスクリーンショットから、KombinatおよびCore独自保管・接続システムへ採用するUI・操作上の教訓を記録する参照領域である。画像は研究用であり、MODへ同梱するTextureや複製対象ではない。

## 項目

- [0. 出典と利用範囲](00-出典と利用範囲.md) — ユーザー提供映像をKombinatのUI・操作研究に限定して利用し、画像・コード・固有表現のコピー元にはしない。
- [1. MonolynのネットワークUIから採るもの](01-MonolynのネットワークUIから採るもの.md) — Monolynの集中資源、生産一覧、選択時ネットワーク表示から、Kombinatへ採用する情報設計を抽出する。
- [2. Arsenal Codexの直接交換から採るもの](02-Arsenal-Codexの直接交換から採るもの.md) — 接続保管庫からPawnへ直接装備し、現在装備を同じ取引で返す操作を、Coreの原子的武器交換の参照とする。
- [3. DSUから採るUIと採らない実装](03-DSUから採るUIと採らない実装.md) — DSUの検索・任意排出・Pawnアクセスは参照するが、中央Mapセルへ内容物を集積する保管方式は採用しない。
- [4. 要求中間素材作成の操作イメージ](04-要求中間素材作成の操作イメージ.md) — 在庫とRecipeを並べ、最終品の要求から不足中間品と総材料を確認する簡潔な操作モデルをKombinatへ適用する。

# 9. 実施順序

## Phase 1：正史の入口を修正

1. 統合資料§1、§7.2、§11.1を中心命題に合わせて改稿する。
2. 「実はディストピア」と読ませる作者断定を、具体的な行為と視点へ置き換える。
3. 本文冒頭に「作者用正本であり、プレイヤーに全て提示しない」と明記する。

## Phase 2：Q0と近未来化要因を隔離

1. 実在指導者名の勲章を独自名へ変更する。
2. 実在作戦名・実被害との直接対応を削除する。
3. 実銃、実在国、外部作品、技術参照元を作者用付録へ移す。
4. 文学作品名のMODは公開名を独自化する。

## Phase 3：製品と設定の数をプレイヤーから隠す

1. 46MOD構想を5つの公開大分類へ再編する。
2. 120惑星・19巨大建造物は必要なものだけクエスト単位で開示する。
3. 838バックストーリーから128件の初期出荷候補を選ぶ。
4. 4,000件は出荷目標から外し、作者用生成アーカイブの上限なし目標へ降格する。

## Phase 4：ゲームメカニクスへ移す

1. 理想郷を余暇、身体選択、無償の生活保障として実装する。
2. 超文明性を、説明文でなく工程と結果へ置く。
3. 無関心を、台帳が数えるもの／数えないもの、クエスト選択肢の欠落として表現する。
4. 少数派の違和感は低頻度イベントと少数のバックストーリーに限定する。

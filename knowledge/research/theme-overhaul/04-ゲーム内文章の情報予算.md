# 4. ゲーム内文章の情報予算

| 媒体 | 上限・原則 |
|---|---|
| MOD紹介文 | 世界の約束を2文、遊びを1文。歴史年表・依存技術の説明を入れない |
| Thing/Research説明 | 機能を先に書く。新固有語は0〜1個。ロアは最後の1文だけ |
| クエスト導入 | 最初の80〜120字で状況と選択を示す。新固有語は最大2個 |
| バックストーリー | 一人の具体的な出来事だけを書く。新固有語は最大1個。用語集を読まないと感情が分からない稿は不採用 |
| イベント通知 | 結果を一読で理解できる普通語を使う。文明史を説明しない |
| 武器・防具 | 現実の国名、制式番号、元銃名を表示しない。性能と使用感は現実的でよい |
| 少数派の記録 | 結論を演説しない。「気づいたが日常へ戻った」程度の弱い違和感を優先する |

## バックストーリー出荷量

既存838件は削除せず、作者用カタログとして保持する。ただしCoreへ一度に全件を出荷しない。

- 初期出荷：Formation 64件＋Mastery 64件＝128件
- 128件の組合せだけで4,096通りを作れるため、通常プレイの多様性には十分
- 各拡張の追加は原則としてFormation 12件＋Mastery 12件以内
- 同じ主張を言い換えた稿、固有名詞だけ差し替えた稿、匿名のソフェルの余録がなければ成立しない稿は出荷対象外
- 既存稿は「理想郷の日常」「正当な資源制約」「できるのに見ない」「少数の違和感」「趣味・意匠」の5桶へ分類し、配分を監査する

現在のカタログは生活描写の質が高い一方、「制裁」「監査」「記録を読み返す者」といった少数派の良心が相対的に多く、同盟全体がすでに十分な自己批判制度を持つようにも読める。テーマに合わせるなら、監査で制度が改善される成功談を減らし、違和感が記録されたが何も変わらなかった稿を少量だけ残す。

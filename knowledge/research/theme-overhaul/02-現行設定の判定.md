# 2. 現行設定の判定

## 2.1 維持すべき中核

| 要素 | 判定 | 理由 |
|---|---|---|
| 本国が本当に豊かで自由 | 維持・最優先 | プレイヤーが同盟へ惹かれる根拠。テーマの片側ではなく土台 |
| 働く義務がない | 維持 | 自己所有という革命の成果を最も簡潔に示す |
| 身体を設計・交換できる | 維持 | メカと狐娘という意匠を、自由の具体物へ変える |
| 復活・再出力が可能 | 維持 | 善意、超文明性、過程への無関心を同時に表せる |
| 悲劇を終わらせる世界革命 | 維持 | 同盟を受動的な楽園ではなく、危険な善意の主体にする |
| 内戦による約99%の経済活動喪失 | 維持 | 無限物量ではない理由。無関心と能力不足の切り分けに必要 |
| メカ、狐娘、古風な機械、現実的な銃器運用 | 維持 | 趣味と視覚的魅力。テーマへの説明責任を負わせない |
| 匿名のソフェル | 維持・役割変更 | 世界の解説者ではなく、記録に残らない差異を拾う稀な観察者にする |

## 2.2 修正が必要な中核記述

| 現行箇所 | 問題 | 修正方向 |
|---|---|---|
| §1「本物のユートピア」と「終わらない対外的暴力」 | 二項対立だけでは「理想と暴力の皮肉」に縮む | 善意・能力・無関心・自己美化の四項を中心にする |
| §7.2「結果の平等は存在しない」「新しい貴族制」「ビロードの手袋」 | 本国の日常を実は偽物だったディストピアへ読ませる | 栄誉と発言力の偏りは残すが、住居・身体・時間・文化・離職の自由を奪う階級ではないと明記する |
| §8.2「虐殺」、§13.1「民族浄化」等の作者による即時判決 | プレイヤーに結論を先に渡し、体験する余地を消す | 行為、結果、当事者の言葉を示す。道徳ラベルは少数派や外部者の発話として限定する |
| §11.1「通常はグリッターワールド級」 | 超文明を既存技術段階へ縮小し、近未来SFとして読ませる | 社会分類と能力尺度を分ける。外見は素朴でも因果・恒星・人格を工業対象にする文明と記す |
| §20.8の実在指導者名勲章 | Q0に直接抵触し、20世紀パスティーシュを強める | 全て架空名へ変更する |
| §22の実在国・実銃系統、§25の外部作品技術名 | 開発メモと正史が混在し、技術の天井を現代へ引き下げる | 作者用「参照元台帳」へ隔離し、ゲーム内名称・説明から除く |
| §23〜24の実在文学作品名によるMOD群 | 作品固有の連想がシオン固有の主題より前へ出る | 独自名称へ変更し、文学由来名は作者用コード名へ降格する |
| §31の4,000バックストーリー目標 | 数が目的化し、プレイヤーが読む一件の意味を薄める | 出荷用の厳選プールと、作者用生成アーカイブを分離する |

## 2.3 現行実装の判定

現時点のKombinat実装は、5資源のWorld台帳、予約、コミット、返還、セーブ状態を持つ基盤であり、テーマ上はほぼ中立である。設計自体を作り直す必要はない。

ただし、将来のUIで「人、食料、居住地、復活対象を全て同じ数値として扱う」場合、同盟の思考様式を非常に強く表現できる。ここで長い説明を出す必要はない。例えば、救出対象の予約が構造材やCellと同じ一覧へ静かに並び、誰もそれを異常扱いしないだけでよい。

# 4. Three-state Core visual lesson

The screenshots suggest a useful three-stage language:

| Reference-like stage | Nexus translation |
| --- | --- |
| Broken/dormant slab | Dormant Core: dark aperture, sealed face, no strong glow. |
| Stable heavy platform | Awake Core: central aperture open, blue-violet depth, one cyan line. |
| Activated red monolith | Critical Core: warning accents only, not default; red-orange for actual danger. |

Nexus Core state rules:

| Nexus state | Visual direction |
| --- | --- |
| Dormant | simple sealed tower, dark void lens, almost no glow. |
| Awake | stable white/ceramic tower, blue-violet aperture, faint cyan ledger line. |
| Low CVE | aperture remains but glow collapses into a small gray-blue point. |
| Damaged | cracked shell, amber warning notch, unstable blue-violet. |
| Permanent shutdown | ash-gray monolith, dead aperture, small red-orange fracture. |

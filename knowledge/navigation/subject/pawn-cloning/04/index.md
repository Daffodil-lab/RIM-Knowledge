# Pawn・生産・複製 04

## 項目

- [9. 次の作業順](/roadmap/09-%E6%AC%A1%E3%81%AE%E4%BD%9C%E6%A5%AD%E9%A0%86.md) — 工業管理画面の基準画像とRimWorld 1.6画面契約を先に固定し、種族非依存の保管基盤とコンビナートを実装してからシオン種族と図像をα版へ統合する。
- [3. シオンという人類](/world/03-%E3%82%B7%E3%82%AA%E3%83%B3%E3%81%A8%E3%81%84%E3%81%86%E4%BA%BA%E9%A1%9E.md) — シオン/Shionは、製造された機械身体と機械超知性に相当する能力を持つ、独立人格の人類である。
- [9. The Hive](/world/09-The-Hive-%E3%82%B6%E3%83%BB%E3%83%8F%E3%82%A4%E3%83%B4.md) — The Hiveは、通常シオン社会の標準ではない、例外的な単一中枢運営を扱う。
- [12. 正史上の禁止境界](/world/12-%E6%AD%A3%E5%8F%B2%E4%B8%8A%E3%81%AE%E7%A6%81%E6%AD%A2%E5%A2%83%E7%95%8C.md) — 新しい設定は、帝国と同盟の連続性と変化、純粋な善意、善意の非対称性、人格と身体の分離を同時に壊さない場合にのみ採用できる。
- [13. 帝国人とシオンの起源](/world/13-%E5%B8%9D%E5%9B%BD%E4%BA%BA%E3%81%A8%E3%82%B7%E3%82%AA%E3%83%B3%E3%81%AE%E8%B5%B7%E6%BA%90.md) — 帝国人とシオンは機械超知性に該当またはそれを上回り得る人類であり、シオンは帝国人の身体基盤から設計された。
- [28. 狐娘型の共有身体](/world/28-%E7%8B%90%E5%A8%98%E5%9E%8B%E3%81%AE%E5%85%B1%E6%9C%89%E8%BA%AB%E4%BD%93.md) — 通常シオンは、史料上確認できるかなり初期の段階から、狐耳と尾を持つ無性の人間型シルエットを共通の身体像としてきた。
- [29. シオンの無性機械身体](/world/29-%E3%82%B7%E3%82%AA%E3%83%B3%E3%81%AE%E7%84%A1%E6%80%A7%E6%A9%9F%E6%A2%B0%E8%BA%AB%E4%BD%93.md) — シオンの狐娘型は外見上の呼称であり、身体に生物学的性別、人間型の内臓、生理現象は存在しない。
- [46. カエラヴィ](/world/46-%E3%82%AB%E3%82%A8%E3%83%A9%E3%83%B4%E3%82%A3.md) — カエラヴィは、人間型の身体に機能する翼を持ち、自然生得型、カエラヴィ改造型、同盟支援型の遺伝的出自を分けて扱う人類である。
- [47. カエラヴィの鳥類身体](/world/47-%E3%82%AB%E3%82%A8%E3%83%A9%E3%83%B4%E3%82%A3%E3%81%AE%E9%B3%A5%E9%A1%9E%E8%BA%AB%E4%BD%93.md) — カエラヴィは、人間型の顔と四肢、背部の機能翼、尾羽、開放的な気嚢系、飛行に適した軽量な身体を共通して持つ。
- [48. カエラヴィの遺伝的出自と鳥類系統](/world/48-%E3%82%AB%E3%82%A8%E3%83%A9%E3%83%B4%E3%82%A3%E3%81%AE%E9%81%BA%E4%BC%9D%E6%80%A7%E9%B3%A5%E9%A1%9E%E7%B3%BB%E7%B5%B1.md) — カエラヴィは自然生得型を基礎に、カエラヴィ改造型と同盟支援型を重ね、六つの遺伝性鳥類系統を出自・改造と直交する基礎分類として扱う。
- [49. 帝鷲系](/world/49-%E5%B8%9D%E9%B7%B2%E7%B3%BB.md) — 帝鷲系は、暗褐色と金色の羽、幅広い指状翼、双窩遠望網膜、強化翼梁を持ち、遠望と搭載力に優れる一方で急離陸と近距離旋回に負担を持つカエラヴィの遺伝性鳥類系統である。
- [50. 猟隼系](/world/50-%E7%8C%9F%E9%9A%BC%E7%B3%BB.md) — 猟隼系は、砂褐色の羽、尖った翼、衝圧鼻弁、硬質初列風切を持ち、急離陸と短距離高速飛行に優れる一方で航続と搭載力に負担を持つカエラヴィの遺伝性鳥類系統である。
- [51. 冠朱鷺系](/world/51-%E5%86%A0%E6%9C%B1%E9%B7%BA%E7%B3%BB.md) — 冠朱鷺系は、緑紫に光る黒羽、赤い裸面、長い冠羽、裸面熱交換帯、多襞嗉嚢を持ち、生食と暑熱に適応する一方で食料需要と寒冷に負担を持つカエラヴィの遺伝性鳥類系統である。
- [52. 白鸛系](/world/52-%E7%99%BD%E9%B8%9B%E7%B3%BB.md) — 白鸛系は、白い体羽、黒い風切羽、赤い眼周囲と下腿、長脛湿地腱、湿地濾過気嚢を持ち、湿地と汚染環境に適応する一方で狭所離陸と近距離回避に負担を持つカエラヴィの遺伝性鳥類系統である。
- [53. 大洋信天翁系](/world/53-%E5%A4%A7%E6%B4%8B%E4%BF%A1%E5%A4%A9%E7%BF%81%E7%B3%BB.md) — 大洋信天翁系は、白い頭胴、暗色の外翼、極端に長い鎌状翼、翼関節固定腱、塩腺を持ち、長距離飛行と水域に適応する一方で離陸と地上行動に負担を持つカエラヴィの遺伝性鳥類系統である。
- [54. 旅鳩系](/world/54-%E6%97%85%E9%B3%A9%E7%B3%BB.md) — 旅鳩系は、青灰色の翼、葡萄色の胸、光沢のある首羽、帰巣磁鉄小体、編隊前庭器を持ち、群飛と集団航法に優れる一方で孤立と強い電磁擾乱に負担を持つカエラヴィの遺伝性鳥類系統である。

# 世界観・正史 02

範囲: 67. CreditとMarkの二国間清算〜71. 軍務貢献認定と帰還権

## 項目

- [67. CreditとMarkの二国間清算](/world/67-Credit%E3%81%A8Mark%E3%81%AE%E4%BA%8C%E5%9B%BD%E9%96%93%E6%B8%85%E7%AE%97.md) — CreditとMarkの二国間清算は、同盟の資源委任評価とカエルムの債務・価格台帳を1 Credit対100 Markで接続する固定の公定評価である。
- [68. カエルム文化産業](/world/68-%E3%82%AB%E3%82%A8%E3%83%AB%E3%83%A0%E6%96%87%E5%8C%96%E7%94%A3%E6%A5%AD.md) — カエルム文化産業は、芸術、文化、料理、衣服、装飾、手工芸品の六部門で、作り手と製造履歴を価値として同盟へ輸出する産業群である。
- [69. カエルム文化後援・交易・課税原則](/world/69-%E3%82%AB%E3%82%A8%E3%83%AB%E3%83%A0%E6%96%87%E5%8C%96%E5%BE%8C%E6%8F%B4%E3%83%BB%E4%BA%A4%E6%98%93%E3%83%BB%E8%AA%B2%E7%A8%8E%E5%8E%9F%E5%89%87.md) — カエルム文化交易は、同盟の十倍文化後援、カエルム国内の通常査定と低額清算、現地勢力の限定買取、取引時の帝国課税を買い手別に分ける。
- [70. 遠征共同体債務履行契約](/world/70-%E9%81%A0%E5%BE%81%E5%85%B1%E5%90%8C%E4%BD%93%E5%82%B5%E5%8B%99%E5%B1%A5%E8%A1%8C%E5%A5%91%E7%B4%84.md) — 遠征共同体債務履行契約は、カエラヴィ個人の身分別債務について共同体が返済履行を引き受け、Mark返済、納税、軍務、追加借入を別台帳で扱う派遣契約である。
- [71. 軍務貢献認定と帰還権](/world/71-%E8%BB%8D%E5%8B%99%E8%B2%A2%E7%8C%AE%E8%AA%8D%E5%AE%9A%E3%81%A8%E5%B8%B0%E9%82%84%E6%A8%A9.md) — 軍務貢献認定は戦闘と任務の危険度を軍功として記録し、元本を減らさず利息相当の履行とし、所定値に達した共同体へ債務完済とは別の正規帰還権を与える。

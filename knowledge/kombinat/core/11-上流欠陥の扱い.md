# 11. 上流欠陥の扱い

Matter Networkはα版の必須経路ではない。将来、正式APIに基づく任意Adapterを実装した場合だけ、Matter Network単体で再現する次の欠陥をCoreとKombinatのRelease Gateから分離する。

- Controller破壊
- Disk取外し
- Stasis
- wealth
- stack
- Quest品
- Container
- Map放棄
- 外部MOD互換
- 上流Harmony patch

上記はKombinat側で修正しない。Adapterとの接続が原因の場合だけ、Kombinat Jobの停止、取消、Buffer保全、Adapter無効化で対処する。

Core独自保管・接続システムで同等の欠陥が再現する場合は、α版からCore側のRelease Gateへ含める。

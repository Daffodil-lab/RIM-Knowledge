# 2. 実装状態の参照

Kombinatの実装済み機能、残るRelease Gate、次の作業は[リリース計画の現在地](/roadmap/08-現在地.md)が所有する。本節は状態を複製せず、中核仕様の各責務を現在地と[次の作業順](/roadmap/09-次の作業順.md)へ接続する。

発注、多段生産、設備、通貨、UI、保存、性能は、それぞれの要件と検証を通過した時点で該当する完成状態へ進む。Red Star、Pawn Foundry、The Hiveの接続時期はリリース計画が所有する。

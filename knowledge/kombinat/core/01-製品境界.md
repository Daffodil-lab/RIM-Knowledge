# 1. 製品境界

```text
Core独自保管・接続システム
  ├─ Network identity／接続graph
  ├─ 実Thing Storage／Filter／容量
  ├─ Import／Export Endpoint
  ├─ 直接転送／手動排出／復旧
  └─ 保管UI／接続Overlay／保存

Kombinat
  ├─ Production Request／Queue
  ├─ Recipe Plan／Job／Batch
  ├─ Kombinat Factory能力／進捗
  ├─ Storage入力予約／出力容量予約
  ├─ Storage上の中間品と多段生産
  ├─ 消費・不足・流通目標
  ├─ 非貨幣の同盟Credit Account
  └─ Core／Red Star／Pawn Foundry Adapter
```

Kombinatは、保管基盤が公開する予約、受渡し、取消、照会eventだけを接続面にする。保管内部の`ThingOwner`、保存Record、検索索引、Network graphを直接走査または変更しない。

自動生産は地面、通常Stockpile、Pawn hauling、工場内在庫を中間経路にしない。Kombinat Plannerは、保管基盤がOperation ID付きで入力Thingと出力容量を確約した工程だけを開始する。工程完了時はStorageの生産Commitが入力消費と出力生成を一度だけ実行する。

接続先はCore独自保管・接続システムの公開予約・取引契約である。KombinatのDomain型はこの契約だけに依存し、保管実装の私有状態を所有しない。

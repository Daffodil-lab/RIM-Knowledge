# 6. 無人生産

Kombinat専用FactoryとKombinat専用Patternは、Pawnがいなくても電力、材料、設備状態を満たせば稼働できる。

外部Recipeは次へ分類する。

- `Kombinat Automated`: 専用Factoryで決定的に実行できる
- `Vanilla Work Required`: PawnとVanilla Billへ任せる
- `Official Adapter Required`: 公開APIによるAdapterがある場合だけ自動化する
- `Unsupported`: 発注候補へ出さない

技能、品質、Inspiration、Tale、Hediff、Quest、World状態等の副作用を持つ外部Recipeを、推測で無人化しない。

Coreと五つの公式DLCについては、[Core・公式DLC量産カタログ境界](/design/55-Core公式DLC量産カタログ境界.md)が`Kombinat Automated`の適格条件、除外条件、Storage取引、出力品質を所有する。

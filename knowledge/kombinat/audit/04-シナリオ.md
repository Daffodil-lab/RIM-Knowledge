# 4. シナリオ

| ID | 状況 | 期待するKombinat挙動 |
|---|---|---|
| S2-001 | 一つの三段Job | 実入力と実出力が一致する |
| S2-002 | 材料が上流にあるが搬入されない | IO待ち。材料消失とは表示しない |
| S2-003 | Input搬入中に保存 | 一回だけ受領する |
| S2-004 | Output回収中に保存 | 一回だけ引き渡す |
| S2-005 | Factory停電 | Buffer保持、処理停止 |
| S2-006 | Factory破壊 | Kombinat所有Bufferを一回だけ回収状態へ置く |
| S2-007 | Output満杯 | 次Batchを開始しない |
| S2-008 | 副産物満杯 | 主出力だけ完成扱いにしない |
| S2-009 | 取消連打 | 終端処理を一回だけ行う |
| S2-010 | 二Jobが同じ材料を待つ | Storage上の同じThing数量を一Jobだけが予約する |
| S2-011 | 外部Recipe | 分類不能ならUnsupported |
| S2-012 | Vanilla作業必須Recipe | Pawn作業待ちとして分離する |
| S2-013 | Stasis中の食料 | 正常。警告・追加費用なし |
| S2-014 | 初期Account生成 | 一回だけ残高適用 |
| S2-015 | 支払連打 | 一回だけ決済 |
| S2-016 | 返金中保存 | 支払と返金の最終差分が一意 |
| S2-017 | 500 Job長期運用 | 履歴を有限化する |
| S2-018 | 全DLC有効 | Kombinat追加層が起動・保存できる |

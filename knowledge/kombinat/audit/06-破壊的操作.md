# 6. 破壊的操作

| 操作 | Kombinatが守るもの |
|---|---|
| Request連打 | Jobを二重生成しない |
| Cancel／Resume連打 | Bufferと通貨を二重精算しない |
| Factory移設・破壊 | Facility割当を解除し、Storage予約と実Thingを安全に維持または解放する |
| Storage Endpoint設定変更 | 成立しない予約を解放し、Jobを接続待ちへ戻す |
| Core Storage接続の消失 | 新規Jobを停止し、最終確定状態と再接続理由を維持する |
| Recipe Def変更 | 進行中JobのPattern versionを保持 |
| Save手編集 | schema不整合を無言補正しない |

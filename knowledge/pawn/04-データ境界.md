# 4. データ境界

| 境界 | 主な内容 | 保存 |
|---|---|---|
| `Pawn Generation Request` | 適合条件、数量、登録方針、Loadout | 完了まで |
| `Pawn Design` | Body、Module、外装、能力、役割、Loadout Profile | 再利用設計として保存 |
| `Individual Archive` | 単一個体の再構築正本 | 登録解除まで |
| `Clone Lineage` | Clone Source、世代、表示上の識別方法 | Sourceが存在する間 |
| `Pawn Instance` | 活動中のRimWorld Pawn正本 | 活動中または死亡処理中 |
| `Dormant Pawn Record` | 生存Pawnの人格状態、身体、内蔵Moduleの停止保存 | 再配備または破棄まで |
| `Recovery Record` | 負傷、死亡、遺体回収、再起動、再資源化の状態 | 終端まで |
| `Loadout Profile` | 具体指定と装備ファミリー、装備ポイント、代替、必須条件 | DesignまたはArchiveから参照 |

# 14. β Definition of Done

次を全て満たした時だけ、β版のPawn生産系を完成とする。

- GEN-001〜008、REG-001〜010、DOR-001〜007、REC-001〜009を満たす。
- INT-001〜006、UX-001〜006、SAVE-001〜006、PERF-001〜004を満たす。
- ADV-001〜010を満たす。
- §12のA〜Jを通過する。
- 監査S-047〜060、S-064〜066を試験へ割り当て、β blockerに該当する試験を通す。
- 適合生成、既定個体、一からの設計、単一個体保存、CloneをUIから実行できる。
- 必要な身体、Module、能力、具体装備が揃ったPawnを反復生産できる。
- Pawn生産に固定回数上限または恒久的な希少部品を要求しない。
- 生存Pawnを資源、通貨、専用容量、継続Tickなしで保管・再配備できる。
- 負傷修復、遺体再起動、登録個体の再実体化が新規生産より低コストで機能する。
- 再資源化済みEphemeral Pawnの構造化個体情報がセーブへ残らない。
- Registered Individualは同時に一実体だけ、Cloneは固有IDを持つ複数実体として存在できる。
- 一人の登録シオンと、そのCloneだけで構成したコロニーを作れる。
- Kombinatの生産・消費・流通という三主題を崩さない。
- 世界内の人格権と、ゲーム上の補充可能な工業ユニットという扱いを混同しない。

# D. 単一個体の登録と再実体化

1. 活動中Pawnを登録する。
2. 死亡、回収、Archive checkpoint、遺体再資源化を行う。
3. 同じ`individualId`、名前、関係、構成で一体だけ再実体化する。
4. 二件の同時再実体化要求の片方が安全に拒否される。

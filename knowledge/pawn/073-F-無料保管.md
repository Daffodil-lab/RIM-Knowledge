# F. 無料保管

1. 生存Pawnへ装備とinventory内Thingを持たせてDormant化する。
2. 着脱品がCore独自保管・接続システムの通常入庫経路またはMapへ一度だけ返却され、容量不足時はDormant化が成立しないことを確認する。
3. 長期間進め、Dormant Pawnの保管料、Need、年齢、Hediffが変化しないことを確認する。
4. 無料で再配備し、同じ個体、身体、内蔵Moduleが一度だけ戻り、保存済みLoadoutから既存装備または代替品を要求できる。

# 4.1 ID

- `designId`: 再利用設計
- `individualId`: 社会的に一人として扱う個体
- `pawnInstanceId`: 一回の活動実体
- `lineageId`: Clone原型と派生関係
- `productionRequestId`: 一回の製造要求
- `recoveryId`: 一回の回収・再生処理

再実体化では`individualId`を維持し、`pawnInstanceId`を更新できる。Cloneでは新しい`individualId`と`pawnInstanceId`を作り、`lineageId`で元を参照する。

# INT-004 装備ファミリー

`MUST`: 武器、防具、工具、医療品等のFamily指定は、作者が明示登録した同用途・同性能帯・同費用帯の候補から具体Thingへ解決する。固定順、重み付き、重複回避、一巡後重複等の簡単な選択規則を使い、任意の全Stat・全Recipe・全MOD装備を動的に最適化しない。

装備ポイントはFamily間の予算、配備量、一式構成を比較する非物理的な計画値である。実材料の代わりに消費せず、完成した装備の資産価値を置換しない。外部MOD装備は明示登録またはAdapterなしにFamilyへ自動参加させない。

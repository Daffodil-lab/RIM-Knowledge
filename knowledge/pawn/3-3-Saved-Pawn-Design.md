# 3.3 Saved Pawn Design

特定の一人ではなく、繰り返し使える製造設計である。身体、Module、外装、能力、役割、装備Profileを保存するが、活動中の関係、経験、傷、個人所有物を自動継承しない。

同じDesignから任意数を生産できる。出力Pawnは既定では別個体であり、必要なら個別に登録できる。

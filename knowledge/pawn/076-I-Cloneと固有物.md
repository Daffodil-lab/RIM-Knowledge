# I. Cloneと固有物

1. 名前付き武器、Quest参照、称号を持つRegistered IndividualをCloneする。
2. Cloneが固有武器、Quest所有権、称号を暗黙複製しない。
3. 身体能力と許可された初期情報だけが複製される。

# INT-006 取消と返却

`MUST`: 生産取消、設計変更、配備失敗時は、未消費資源、完成済み装備、部分完成Bodyを追跡し、複製せずCore独自保管・接続システムの通常入庫経路またはMap上の受入先へ返却するか、Factory Buffer内で明示的に再利用する。

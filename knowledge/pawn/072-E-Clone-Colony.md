# E. Clone Colony

1. 一体のRegistered IndividualをClone Sourceにする。
2. 同じ原型のCloneを二十体注文する。
3. 同名・同外見を許可しつつ、全Cloneが固有IDで選択できる。
4. 原型とCloneだけでコロニーを運営できる。
5. 各Cloneの経験、傷、装備が独立して変化する。

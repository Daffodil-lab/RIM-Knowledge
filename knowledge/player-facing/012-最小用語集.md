# 最小用語集

| 語 | プレイヤーが知る意味 |
|---|---|
| シオン | 狐耳と尾を持つ無性の製造身体を共有し、文化と自己認識によって自らを人類とみなす機械の民。一人ずつ別の人格を持つ |
| 帝国 | シオンを作り、律法と聖なる秩序で善い世界を築こうとした旧文明 |
| 同盟 | 三つの条約で対等な評議会を結び、帝国から継承した力で自由で俗世的な本物の理想郷を築いた共同体 |
| 本国 | 飢えと望まない労働の大半を克服した同盟の故郷 |
| 同盟通貨 | 生存権や忠誠ではなく、交易・契約・個別の財やサービスを決済する同盟のお金 |
| 独立開拓団 | 数人から国家級、生活共同体から契約軍事組織まで存在し、本国の正規指揮や保証支援へ恒常所属しない勢力の大分類 |
| Cell | 物、身体、設備を作り替える自己増殖可能な工業媒体 |
| エネルギー（仮称） | 身体や設備を動かす力の発生、供給、蓄積、輸送を含む技術分野 |
| エネルギー結晶（仮称） | エネルギーそのものを外地へ運び、改造身体や高度装備を動かす物理資源 |
| 凝縮真空 | 同盟時代に確立された、エネルギー分野の技術または形態 |
| 弾薬結晶 | 全シオン系遠距離武器が、その場で固有弾薬を作るために使う物理資源 |
| ソフェル | 記号と現実を直接結び付けるイェツィラーを読み書きする専門家 |
| Core独自保管・接続システム | α版から実Thingの保管・検索・直接入出庫・任意排出と接続を担うCore基盤 |
| Kombinat | Core独自基盤へ接続し、発注・多段生産・工場・消費表示・同盟通貨を扱うCore追加層 |
| Pawn Foundry | シオンの適合生成、個体設計、登録、Clone、休眠保管、回収再生を行うβ版のCore設備 |
| The Hive | 後期実装予定の、例外的な単一中枢人格と端末群 |
| Red Star | 正式任務と責務を負う代わりに、本国の優れた継続支援を受ける派遣開拓団 |

これ以上の語は、登場するクエストや機能の中でその都度説明します。

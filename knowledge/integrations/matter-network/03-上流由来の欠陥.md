# 3. 上流由来の欠陥

任意互換Adapterの試験でMatter Network単体に再現する問題はKombinatの欠陥に分類せず、CoreまたはKombinatのRelease blockerにも数えない。Kombinat側の回避patchを作らない。

Core独自システムで同等の問題が再現する場合はCore側の欠陥である。Matter Networkがなくても正規プレイループが成立することはα以後のRelease Gateとする。

Kombinat有効時だけ発生する問題は、次の順で切り分ける。

1. KombinatのJob、Factory、通貨、UIを無効にして再現するか確認する。
2. Matter Network単体で再現する場合は上流挙動として終了する。
3. Kombinatとの接続でのみ再現する場合はKombinat統合部の欠陥とする。
4. 修正にMatter Network内部の変更が必要なら、Adapterを実装しないか無効化する。

上流挙動を危険と評価した場合、正規UIやCore独自基盤へ回避処理を混入させない。任意Adapterだけを安全に停止する。

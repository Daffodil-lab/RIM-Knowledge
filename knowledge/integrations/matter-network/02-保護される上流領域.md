# 2. 保護される上流領域

次は全て上流の責務であり、任意互換Adapterを検討する場合もCoreとKombinatの設計・Release Gate・欠陥修正対象から除外する。

- ControllerとNetwork identity
- Cableによる接続、結合、分割
- Drive、Disk、容量Tier、容量計算、Disk取外し
- Network InterfaceとPawnによる出入庫
- Matter IO Portによる自動Import／Export
- Network Capacitor、Reserve Cell、予備電力
- Fuel Relay
- Network内のThing保存方式、stack、identity、検索、Filter
- 保管中ThingのTick、腐敗、温度、劣化、充放電、孵化等の扱い
- wealth算入、破壊、排出、紛失、Map lifecycle
- Quest品、名前付き品、Container、未知Comp、外部MOD品の互換挙動
- Matter Network自身のHarmony patch、UI、Scribe、Def、Texture、翻訳

Kombinatから上記へHarmony patch、reflection、private field参照、型差替え、prefixによる元処理停止、追加の入庫拒否、独自Recovery、独自Over Capacity、独自stack再構成を行わない。

Core独自システムでは、同じプレイ責務をCore側が自ら所有・試験する。本節を理由に、独自システムの容量、破壊、保存、Tick、互換性等を外部責務へ残さない。

# 2. 基本定義

| 項目        | 内容                                  |
| --------- | ----------------------------------- |
| 呼称        | 匿名のソフェル                             |
| 本名        | 非公開                                 |
| 種族        | シオン                                  |
| 専門職       | ソフェル                                 |
| 出身Era     | ImperialPeak                        |
| 現在のEra    | ModernUnion                         |
| 性別表現      | 女性                                  |
| 年齢        | ImperialPeak以前には存在しない。製造以来、非常に長期間活動 |
| 能力Tier    | およそ＋12                              |
| Quality目安 | 1.10～1.20                           |
| 主職能       | 律法、イェツィラー、記録、歴史編纂、聞き取り              |
| 副職能       | 医療、工学、文化、政治、惑星調査、軍事基礎               |
| 軍事水準      | 一般的な正規兵士と同程度                        |
| 現在の役割     | プレイヤー向けロアと人物経歴の編纂者                  |
| 特徴        | 広い教養と高い総合能力を持つが、頂点級の専門家ではない         |
匿名のソフェルは、一般的なシオンより明確に優秀であり、一般的なソフェルの中でも高い総合能力を持つ。
ただし、水仙、アルコテック級存在、最高位の大ソフェル、単一分野へ極端に特化した人物には及ばない。

# 23. 固有特性構成

固定特性は次の4件を推奨する。
1. 博識のソフェル
2. 名を記さない者
3. 記録を捨てない
4. 鉄の意志
Vanillaの「物覚えが早い」「勤労者」は、固有特性と重複するため使用しない。
